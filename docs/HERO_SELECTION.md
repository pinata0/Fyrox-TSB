# 영웅 선택 화면 / 2026-11-12

오버워치 영웅 선택창을 검색하고 [Windows Central 리뷰의 실제 선택 화면](https://www.windowscentral.com/gaming/overwatch-2)을 참고했다. [참고 스크린샷](https://cdn.mos.cms.futurecdn.net/qZYudRBPX7Nkfb58scq8Rn.jpg)의 큰 3D 영웅, 모드·맵 안내, 팀 슬롯, 포지션별 초상화와 확정 버튼을 TSB의 6인 팀·전열/중열/후열 편성에 맞춰 구성했다.

## 조작과 표시

- 왼쪽 상단 제목은 **경쟁전**, 아래 색상 안내는 **맵 이름 / ATTACK 또는 DEFEND** 한 줄만 표시한다. 6대6·2CP·거점·라운드 표시는 생략한다. 하단 영웅 선택 버튼은 공통 배경 상자 없이 개별 카드로 배치한다.

- 선택창 뒤에는 **현재 활성화된 거점의 전경**을 실시간으로 흐리게 표시한다. 요정왕국 성·엘프 도시의 A/B 거점마다 주변 지형을 내려다보는 전용 시점을 사용하며, A 점령 후 B 활성화·맵 변경 시 자동으로 바뀐다. 플레이어 위치·마우스 방향·소속 팀과 무관하게 현재 거점을 보여준다. 맵과 전투는 매 프레임 갱신하며, 큰 3D 영웅·선택 모션·볼 당기기·UI는 선명하게 유지한다. 배경 카메라는 선택창이 보일 때만 켜지며, 창을 닫으면 일반 게임 화면으로 돌아간다.
- 캐릭터에는 선택창 전용 스튜디오 돔 조명을 사용한다. 정면 양쪽·상부·측면·아래쪽의 그림자 없는 보조광 6개로 얼굴과 의상을 밝히며, 야간 맵에서도 눈·볼·머리 장식이 잘 보이도록 한다. 선택창을 닫으면 조명은 꺼지고, 별도 렌더 레이어로 거점 배경에는 영향을 주지 않는다.
- 우이의 미리보기 위치는 우이 본체를 기준으로 맞춘다. 에루를 함께 노출하려고 우이를 위로 올리지 않으며, 에루는 하단 팀 슬롯·영웅 카드에 가려질 수 있다.

- 큰 3D 캐릭터의 양쪽 볼을 왼쪽 버튼으로 누른 채 드래그하면 볼이 늘어나고 고유 반응이 반복된다. 놓으면 탄성 복원과 캐릭터별 놓기 반응을 재생한다. 15명 원작 조사·재생 시간·3D 대응 범위는 [볼 당기기 문서](CHEEK_INTERACTIONS.md)에 있다.

- 선택한 영웅의 이름은 오른쪽 상단에 크게 표시하고, 이름과 아래 아이콘 줄의 오른쪽 끝을 맞춘다. 시온 더 다크불릿처럼 긴 이름도 같은 글자 크기를 유지하며, 넓은 이름 영역에 한 줄로 표시한다. 이름 아래에는 종족·포지션·성격(속성) 순서로 원작의 투명 아이콘만 표시하며, 특성 이름과 스킬 설명 패널은 표시하지 않는다. 하단 영웅 목록·팀 슬롯·선택 확정 버튼은 화면 중앙에 맞추고, 카드 이름과 버튼 문구도 중앙 정렬한다. 성격 시너지·포지션 인원 상자·캐릭터 카드·팀 슬롯에도 원작 마커를 적용한다. [출처와 투명 PNG 처리](TRAIT_MARKERS.md).
- 열별 인원은 하단 영웅 목록 바로 위에 전열·중열·후열 순서의 가로 상자 3개로 표시하며, 각 상자는 해당 열 영웅 묶음의 가운데에 맞춘다. 각 상자는 **포지션 아이콘 + 현재 인원 / 최대 인원**이며, 3/3이면 강조한다. 팀 성격(속성) 시너지 아이콘은 선택창 왼쪽의 맵 안내 아래에 표시한다.
- 성격(속성) 시너지는 팀원 한 명당 아이콘 하나씩, 최대 6개를 가로로 절반씩 겹쳐 표시한다. 인원이 많은 속성부터 묶고 같은 수이면 기본 속성 순서를 유지한다. 각 속성의 두 명 단위는 유색, 홀수로 남은 한 명은 무색(흑백)이다. 순수 3·광기 2·냉정 1이면 유색 순수 2 → 무색 순수 1 → 유색 광기 2 → 무색 냉정 1 순서다. 속성 이름·인원 숫자·팀 공격력 증가 문구는 표시하지 않는다.
- 선택 불가 영웅은 정원 초과·팀원 중복·교체 잠금 등 이유에 관계없이 카드(초상화·성격 마커·배경·이름)의 색상을 유지한 채 같은 비율로 어둡게 표시한다. 미리보기 중에도 어두운 표시를 유지하고 확정은 거절한다. 확정 버튼도 비활성 상태에서는 원래 색상을 어둡게 표시한다. 정원이 찬 열의 기존 플레이어는 같은 열 내 교체가 가능하며, 팀원 중복 금지는 유지한다. 자리가 비면 즉시 원래 밝기로 돌아온다. 서버도 동일하게 판정하므로 꽉 찬 다른 열의 봇과 교환하여 진입할 수 없다.

- 초상화 클릭·방향키는 미리보기다. 실제 팀 편성은 확정 전까지 바뀌지 않는다.
- 캐릭터를 바꾸거나 같은 초상화를 다시 클릭하면 고유 선택 모션을 2.4초 재생하고 대기로 전환한다.
- 같은 초상화를 0.5초 안에 더블클릭하거나, 미리보기할 영웅을 선택한 뒤 스페이스바를 누르면 선택을 확정한다. 선택 확정 버튼·F5도 동일하게 서버에 요청하며, 선택 불가 조건과 서버 승인 절차를 유지한다. 채팅 입력 중 스페이스바는 확정하지 않는다. 경기 시작 전 로비에서 연 선택창은 확정 후 로비로 돌아온다.
- 게임 시작으로 연 선택창 상단에는 서버 준비 타이머를 올림한 **게임 시작까지 N초**를 표시한다. 영웅 선택이 승인되어도 준비 중에는 선택창을 유지하며, 준비시간이 끝나면 자동으로 인게임으로 전환한다. 시간이 먼저 끝났다면 영웅을 확정하고 서버 승인을 받은 직후 전환한다. 초상화 미리보기만으로는 자동 입장하지 않는다.
- 현재 캐릭터, 미리보기, 선택 불가 초상화를 색상/밝기로 구분한다. 팀원 중복·포지션 상한·스폰 이탈은 이유를 표시한다. 팀 6슬롯·성격 조합 아이콘·포지션 인원을 표시한다.
- H로 열기/닫기, Esc로 확정 없이 닫기, F5로 시작·복귀. 준비 중 취소는 로비로 돌아가며 게임 참가를 눌러도 준비가 끝나기 전에는 선택창으로 돌아온다. 선택창이 열려도 경기는 계속된다. 미리보기 모델은 전투 공간과 떨어진 클라이언트 전용 무대이며 판정에 관여하지 않는다.

## 게임 중 교체 판정

서버가 현재 스폰 중심 기준 **좌우 6.5m, 앞뒤 3m, 높이 0~2.25m**의 구역을 검사한다. 바닥의 민트 경계선과 H 안내가 현재 아군 구역을 보여준다. 반대 팀 스폰과 이전 거점의 스폰으로는 교체할 수 없다. 선택창을 열어둔 상태에서 구역 밖으로 밀려나면 화면이 닫히고, 늦게 도착한 교체 요청도 서버가 거절한다.

| 진행 | 공격 팀 중심 Z | 수비 팀 중심 Z |
|---|---:|---:|
| A 거점 | -13m | 14m |
| B 거점 | 16m | 44m |

스폰 배치는 X=-4.5~4.5m다. 공수 교대 시 공격/수비 팀에 맞춰 기준을 바꾼다. 로비·준비 시간·라운드 사이·종료·사망 중의 기존 선택도 유지한다. 체력·위치·E 쿨타임·리스폰 대기를 회복하지 않는다. 캐릭터를 교체하면 진행 상태와 관계없이 새 무기의 탄창을 가득 채우고 진행 중인 재장전을 종료한다. 봇과 교환할 때도 양쪽에 적용하며, 같은 캐릭터 재확정이나 거부된 요청은 탄약·재장전 상태를 바꾸지 않는다. 기존 중복 금지·포지션 최대 3명·봇 교환 규칙을 그대로 사용한다.

## 궁극기 보존

다른 캐릭터로 실제 교체할 때 `min(현재 게이지, 15%)`를 적용한다.

| 교체 전 | 교체 후 |
|---:|---:|
| 0% | 0% |
| 7.5% | 7.5% |
| 15% | 15% |
| 80% 또는 100% | 15% |

같은 캐릭터 재확정·거부된 요청에는 보존 상한을 적용하지 않는다. 봇과 교환할 때도 각자의 게이지에 독립적으로 적용한다. 사망/리스폰은 원래 게이지를 유지하고 새 공수 라운드는 0%로 초기화한다. UI에 표시된 수치는 소수점을 반올림하며 서버는 소수 게이지를 유지한다.

## 선택 모션

15개 `.blend`와 FBX에 **Select 456~528프레임 / 30fps**를 추가했다. 기존 10종과 합해 캐릭터당 11종이다. 원작 캐릭터 특징에 맞춰 새로 작성한 선택 인사이며 원작의 특정 영상을 그대로 복제한 동작은 아니다.

| 캐릭터 | 제스처 |
|---|---|
| 비비 | 가슴 앞에 손을 모으는 인사 |
| 나이아 | 손을 흔들며 가볍게 인사 |
| 에르핀 | 양팔을 벌리고 턱을 드는 여왕 자세 |
| 이드 | 초승달 의자에 앉아 기지개 |
| 아야 | 한 손으로 꽃잎 양산을 유지하며 다른 팔로 인사 |
| 피코라 | 양손을 볼 옆으로 올리는 자세 |
| 클로에 | 인형을 안는 듯한 팔 모으기 |
| 리뉴아 | 양팔과 손목으로 시간을 지휘하는 자세 |
| 마요 | 손에 든 수집품을 살피는 자세 |
| 벨라 | 팔을 펼치며 상체를 흔드는 유령 인사 |
| 우이 | 개구리 위에서 양손 인사 |
| 버터 | 손 흔들기와 한쪽 다리 들기 |
| 코미 | 하품과 한쪽 팔 기지개 |
| 힐데 | 안경을 고쳐 쓰며 고개 끄덕이기 |
| 시온 | 고개를 돌리고 손을 드는 인사 |

선택 인사의 얼굴은 기존 기본 표정이며, 볼 당기기에서는 별도의 눈·입 변형과 눈물·손·상체 반응을 사용한다. 선택창 미리보기에서는 손 무기를 숨긴다. `scripts/add_selection_motions.py`가 리그 동작을 갱신하고 256×256 초상화를 만든다. 기존 메시·삼면도는 유지한다. `scripts/verify_character_art.py`는 총 165개 동작의 포즈 변화·가중치·60개 반복 구간을 검사한다.

### 유령 벽 통과 중 교체 제한 (2026-11-13)

살아 있는 캐릭터가 벽과 겹치면 선택을 잠근다. 벽 밖으로 나온 뒤 기존 스폰·준비·사망 규칙에 따라 변경한다. 팀 내 봇과 캐릭터를 교환할 때도 해당 봇이 벽 안에 있으면 변경을 거절하여 일반 종족이 벽 안에 갇히지 않게 한다.
