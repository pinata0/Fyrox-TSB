# 영웅 선택 화면 / 2026-11-12

오버워치 영웅 선택창을 검색하고 [Windows Central 리뷰의 실제 선택 화면](https://www.windowscentral.com/gaming/overwatch-2)을 참고했다. [참고 스크린샷](https://cdn.mos.cms.futurecdn.net/qZYudRBPX7Nkfb58scq8Rn.jpg)의 큰 3D 영웅, 모드·맵 안내, 팀 슬롯, 포지션별 초상화와 확정 버튼을 TSB의 6인 팀·전열/중열/후열 편성에 맞춰 구성했다.

## 조작과 표시

- 큰 3D 캐릭터의 양쪽 볼을 왼쪽 버튼으로 누른 채 드래그하면 볼이 늘어나고 고유 반응이 반복된다. 놓으면 탄성 복원과 캐릭터별 놓기 반응을 재생한다. 15명 원작 조사·재생 시간·3D 대응 범위는 [볼 당기기 문서](CHEEK_INTERACTIONS.md)에 있다.

- 성격·종족·포지션은 원작의 투명 마커와 이름을 함께 표시한다. 성격 시너지·포지션 제목·캐릭터 카드·팀 슬롯에도 적용한다. [출처와 투명 PNG 처리](TRAIT_MARKERS.md).

- 초상화 클릭·방향키는 미리보기다. 실제 팀 편성은 확정 전까지 바뀌지 않는다.
- 캐릭터를 바꾸거나 같은 초상화를 다시 클릭하면 고유 선택 모션을 2.4초 재생하고 대기로 전환한다.
- 선택 확정 버튼·Enter로 서버에 요청한다. 승인과 해당 캐릭터 상태 수신 후 1인칭 조작으로 복귀한다. 로비의 호스트가 확정하면 경기도 시작한다.
- 현재 캐릭터, 미리보기, 선택 불가 초상화를 색상/밝기로 구분한다. 팀원 중복·포지션 상한·스폰 이탈은 이유를 표시한다. 팀 6슬롯·현재 성격 인원·공격력 시너지·포지션 인원·LMB/E/Q·종족 패시브를 표시한다.
- H로 열기/닫기, Esc로 확정 없이 닫기, F5로 시작·복귀. 선택창이 열려도 경기는 계속된다. 미리보기 모델은 전투 공간과 떨어진 클라이언트 전용 무대이며 판정에 관여하지 않는다.

## 게임 중 교체 판정

서버가 현재 스폰 중심 기준 **좌우 6.5m, 앞뒤 3m, 높이 0~2.25m**의 구역을 검사한다. 바닥의 민트 경계선과 H 안내가 현재 아군 구역을 보여준다. 반대 팀 스폰과 이전 거점의 스폰으로는 교체할 수 없다. 선택창을 열어둔 상태에서 구역 밖으로 밀려나면 화면이 닫히고, 늦게 도착한 교체 요청도 서버가 거절한다.

| 진행 | 공격 팀 중심 Z | 수비 팀 중심 Z |
|---|---:|---:|
| A 거점 | -13m | 14m |
| B 거점 | 16m | 44m |

스폰 배치는 X=-4.5~4.5m다. 공수 교대 시 공격/수비 팀에 맞춰 기준을 바꾼다. 로비·준비 시간·라운드 사이·종료·사망 중의 기존 선택도 유지한다. 체력·위치·E 쿨타임·리스폰 대기를 회복하지 않는다. 전투 중 탄약은 새 무기의 탄창 이하로 유지한다. 기존 중복 금지·포지션 최대 3명·봇 교환 규칙을 그대로 사용한다.

## 궁극기 보존

다른 캐릭터로 실제 교체할 때 `min(현재 게이지, 15%)`를 적용한다.

| 교체 전 | 교체 후 |
|---:|---:|
| 0% | 0% |
| 7.5% | 7.5% |
| 15% | 15% |
| 80% 또는 100% | 15% |

같은 캐릭터 재확정·거부된 요청에는 보존 상한을 적용하지 않는다. 봇과 교환할 때도 각자의 게이지에 독립적으로 적용한다. 사망/리스폰은 원래 게이지를 유지하고 새 공수 라운드는 0%로 초기화한다. UI에 표시된 수치는 소수점을 반올림하며 서버는 소수 게이지를 유지한다.

## 선택 모션

15개 `.blend`와 FBX에 **Select 456~528프레임 / 30fps**를 추가했다. 기존 10종과 합해 캐릭터당 11종이다. 원작 캐릭터 특징에 맞춰 새로 작성한 선택 인사이며 원작의 특정 영상을 그대로 복제한 동작은 아니다.

| 캐릭터 | 제스처 |
|---|---|
| 비비 | 가슴 앞에 손을 모으는 인사 |
| 나이아 | 손을 흔들며 가볍게 인사 |
| 에르핀 | 양팔을 벌리고 턱을 드는 여왕 자세 |
| 이드 | 초승달 의자에 앉아 기지개 |
| 아야 | 한 손으로 꽃잎 양산을 유지하며 다른 팔로 인사 |
| 피코라 | 양손을 볼 옆으로 올리는 자세 |
| 클로에 | 인형을 안는 듯한 팔 모으기 |
| 리뉴아 | 양팔과 손목으로 시간을 지휘하는 자세 |
| 마요 | 손에 든 수집품을 살피는 자세 |
| 벨라 | 팔을 펼치며 상체를 흔드는 유령 인사 |
| 우이 | 개구리 위에서 양손 인사 |
| 버터 | 손 흔들기와 한쪽 다리 들기 |
| 코미 | 하품과 한쪽 팔 기지개 |
| 힐데 | 안경을 고쳐 쓰며 고개 끄덕이기 |
| 시온 | 고개를 돌리고 손을 드는 인사 |

선택 인사의 얼굴은 기존 기본 표정이며, 볼 당기기에서는 별도의 눈·입 변형과 눈물·손·상체 반응을 사용한다. 선택창 미리보기에서는 손 무기를 숨긴다. `scripts/add_selection_motions.py`가 리그 동작을 갱신하고 256×256 초상화를 만든다. 기존 메시·삼면도는 유지한다. `scripts/verify_character_art.py`는 총 165개 동작의 포즈 변화·가중치·60개 반복 구간을 검사한다.

## 검증과 파일

- `src/game.rs`: 스폰 구역과 서버 선택 판정, 궁극기 보존.
- `src/presentation/selection.rs`: 무대·미리보기·포지션별 초상화·팀 표시.
- `tests/selection.rs`: 양 팀/A·B/공수 교대/구역 경계/이전·적 스폰/보존 상한/동일 선택/거부/체력·쿨타임 유지.
- `src/net.rs`: 실제 UDP에서 살아 있는 참가자의 교체·관전자 전파·구역 이탈 직후 요청 거부·낮은 게이지 유지.
- `--selection-review`: 15명 두 포즈씩 총 30개 실제 GPU 캡처 후 종료. `artifacts/preview-selection-*.png`에 저장한다.
- `artifacts/selection-gallery-final.log`: 15명 전체 선택창 렌더 완료.
- 최종 전체 검사와 수동 입력 확인 범위는 [작업 기록](WORK_LOG.md)에 기록한다.

### 유령 벽 통과 중 교체 제한 (2026-11-13)

살아 있는 캐릭터가 벽과 겹치면 선택을 잠근다. 벽 밖으로 나온 뒤 기존 스폰·준비·사망 규칙에 따라 변경한다. 팀 내 봇과 캐릭터를 교환할 때도 해당 봇이 벽 안에 있으면 변경을 거절하여 일반 종족이 벽 안에 갇히지 않게 한다.
