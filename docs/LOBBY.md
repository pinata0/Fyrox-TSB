# 대전 로비 / 2026-11-13

홈과 로비 사이에 [방 선택 화면](ROOM_BROWSER.md)을 추가했다. 방 생성·참여·웹 목록 조회는 방 선택에서 처리하며, 로비의 돌아가기는 접속을 유지한 채 방 목록을 연다. 기존 아래 기록의 홈→로비 직행 흐름은 이 흐름으로 대체한다.

홈과 경기 사이의 전체 화면 Fyrox UI는 `src/presentation/lobby.rs`에서 구현한다. 홈 일러스트에 어두운 녹색 오버레이, 민트색 우리 팀과 분홍색 상대 팀, 중앙 맵 카드와 금색 시작 버튼을 사용한다. 1280×800 기준으로 종횡비를 유지해 중앙 정렬하며 화면 표시와 클릭 영역에 같은 변환을 사용한다.

## 동작

- 기본 실행은 홈에서 서버를 열지 않는다. 플레이 → 방 만들기에서 UDP 28080 호스트를 시작한다. `--solo`는 오프라인 방을 만든다. `--host`, `--join`, `--online-session`의 기존 사전 접속과 초대 검증을 유지한다.
- 방 참여하기는 IP:포트 입력 창을 연다. IPv4와 `[IPv6]:포트`, 커서 이동·Home/End·Backspace/Delete를 지원한다. 잘못된 주소·포트 0·미지정 주소·멀티캐스트는 연결 전에 거부한다. 비동기 UDP 접속 중에는 시작과 영웅 선택을 막는다. 접속 오류 시 방 나가기 후 다시 시도할 수 있다.
- 각 팀은 최대 6칸이며 **혼자서도 시작 가능**하다. 새 방은 플레이어를 제외하고 모두 비어 있다. 방장/오프라인 연습에서 빈 유저 블록을 누르면 15명 영웅 선택창을 열고, 선택한 영웅 적용으로 봇을 추가한다. 봇 블록에서는 영웅 변경과 봇 삭제를 지원한다. 취소는 변경하지 않는다. 같은 팀 영웅 중복과 포지션별 최대 3명 제한을 표시하며, 인간 슬롯·참가자·진행 중 경기는 편집할 수 없다.
- 빈 슬롯은 AI·피격·부활·거점·팀 시너지에 포함되지 않는다. 맵 변경·시작·재시작에도 빈 슬롯과 봇 영웅을 보존한다. 어느 한 팀이 비어 있으면 경기 시간과 거점 진행을 멈추고 자유 연습 HUD를 표시한다. 상대가 참가하면 일반 경기 규칙을 진행한다.
- 참가자는 빈 슬롯부터 배정하며 빈 슬롯이 없으면 봇을 대체한다. 연결 종료 시 자동 봇 충원 없이 슬롯을 비운다. TSBE 스냅샷으로 점유 상태를 동기화하므로 호스트와 참가자 모두 새 빌드가 필요하다.
- 각 팀 6칸에 서버에서 받은 닉네임과 선택한 영웅의 얼굴 초상화를 표시한다. 내 팀이 항상 왼쪽이다. 나/방장/BOT 표시와 실제 인간 접속 수를 구분하고, 긴 닉네임은 줄인다. 별도 계정 프로필 이미지의 다운로드·동기화는 현재 프로토콜에 없어 영웅 초상화를 사용한다.
- 맵 카드와 선택 창에 **요정왕국 성 / 엘프 도시**를 표시한다. 카드 선택은 미리보기이고 **이 맵 선택**으로 확정한다. 취소하면 기존 맵을 유지한다. 호스트/연습만 경기 전·종료 후에 변경할 수 있으며, 참가자는 스냅샷의 맵 ID에 맞춰 충돌·스폰·거점·모델을 자동으로 바꾼다. 방 생성 전 선택 및 경기 재시작에서도 유지된다. 각 맵의 `assets/maps/<slug>/preview.png`를 표시한다. [엘프 도시 제작 기록](ELF_CITY.md).
- 영웅 선택 → 확정은 로비로 돌아오며 경기를 시작하지 않는다. 방장/연습의 게임 시작 버튼은 즉시 경기 준비를 시작하며, 서버 상태를 받은 모든 플레이어를 캐릭터 선택 화면으로 전환한다. 선택창 상단에 **게임 시작까지 N초**를 표시한다. 기존 8초 준비시간은 선택 중에도 진행되며, 영웅을 확정해도 시간이 남으면 선택창을 유지한다. 시간이 끝나면 서버에서 승인한 영웅으로 자동 입장하고, 시간 만료 후 확정하면 승인 직후 입장한다. 미확정 상태는 선택창에 남는다. 로비 팝업·방 목록·홈·설정 메뉴·기존 선택창을 열어 둔 참가자도 전환하며, 채팅 초안은 보존한다. 시작 전 진행 중이던 선택 확정은 화면 전환 후 자동 입장이나 로비 복귀를 일으키지 않는다. 반복 스냅샷에는 선택창을 다시 열지 않으며, 다음 경기 시작 시 다시 전환한다. 선택창을 취소하면 로비로 복귀한다. 준비 중 게임 참가를 누르면 선택창으로 돌아가며, 준비시간이 끝나기 전에는 인게임으로 넘어갈 수 없다.
- 홈으로 돌아가기는 방 접속을 유지한다. 방 나가기는 세션을 해제하고 로비의 방 만들기/참여하기로 돌아간다. 호스트가 방을 나가면 기존 프로토콜의 타임아웃으로 참가자의 연결이 종료된다.
- Tab/위·아래 방향키로 가능한 동작만 순회, Space 실행, Enter 채팅, Esc 팝업 닫기/홈 복귀, F5 시작. 채팅은 로비·맵 선택·영웅 선택에 공통으로 표시되며 입력 중 메뉴 선택을 막는다. 화면·맵·방 전환에도 최근 64개 기록과 초안을 보존하고 현재 방에만 송수신한다. 로비가 게임 이동·공격·마이크 단축키 입력을 소비하고 마이크 송신을 중지한다. 팝업 뒤의 버튼은 클릭되지 않는다.

## 검증

```powershell
cargo test --locked --bin tsb
cargo clippy --locked --all-targets -- -D warnings
cargo build --locked --bins
target/debug/tsb.exe --lobby-review
target/debug/tsb.exe --lobby-review --lobby-review-small
target/debug/tsb.exe --lobby-review --lobby-review-wide
```

로비 테스트는 시작 권한·연결 상태·주소 검증·해상도별 클릭 영역·모달 차단, 실제 로컬 UDP 참가자의 팀/닉네임 수신과 호스트 시작을 검사한다. `--lobby-review`와 `--home-review`는 홈 → 참여 창/잘못된 주소 → 방 생성 → 맵 선택 → 영웅 확정/로비 복귀 → 홈/로비 복귀 → 시작 취소 → 실제 경기 진입을 검사한다. 1920×1200, 960×640, 1920×800의 11단계 실제 GPU PNG를 `artifacts/preview-lobby-*`에 저장한다.

프로필·맵·모달 글자와 화면 경계를 세 해상도에서 확인했다. 클라이언트 테스트 8개 통과, 오디오 장치 테스트 1개는 원래 ignored 상태다. 기존 헤드리스 전체 회귀 검사는 125개 통과, 변경하지 않은 게임 로직의 테스트 4개 실패다. 실패는 스폰 밖 피해 판정, 유령 벽 접촉 동기화, 성 B 구역 동선, 스폰 밖 영웅 변경 조건이며 `artifacts/lobby-regression-all.log`에 보관한다.

## 1인 연습 / 봇 편집 검증

`tests/lobby_bots.rs`에서 두 맵의 1인 이동·시간 제한 없는 연습·빈 슬롯 비부활, 봇 영웅/포지션 규칙, 맵/시작/재시작 보존, 실제 UDP 추가·변경·삭제 동기화와 참가 슬롯 배정을 검사한다. 로비 UI 테스트는 편집 권한과 세 해상도 클릭 영역·모달 차단을 검사한다. `--lobby-review`의 17~24단계는 빈 로비, 봇 영웅 선택, 추가, 변경, 삭제, 취소, 1인 경기 진입을 캡처한다. 이번 변경 검증 로그는 `artifacts/solo-bots/`에 저장한다.

최종 검사: 헤드리스 테스트 143개와 클라이언트 테스트 13개 통과(오디오 장치 테스트 1개는 기존 ignored), `cargo fmt --all -- --check`, `cargo clippy --locked --all-targets -- -D warnings`, `cargo build --locked --bins` 통과. 960×640, 1920×1200, 1920×800에서 확장된 로비 GPU 검증이 모두 `LOBBY_REVIEW_OK`로 종료했고 봇 선택창의 초상화·문구·버튼을 확인했다.
