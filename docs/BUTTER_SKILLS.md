# 버터 새총 모션

`Play.cmd`로 개발 빌드를 실행합니다. 버터를 선택하고 좌클릭을 눌렀다 놓아 발사합니다. E는 저학년, Q는 고학년이며 궁극기 게이지가 100일 때 사용할 수 있습니다.

## 동작

- 평소에는 오른손만 새총 손잡이를 잡습니다. 좌클릭을 누르면 왼손이 줄을 당기며 몸의 중심이 뒤로 이동합니다. 계속 누르고 있어도 자동 발사하지 않습니다. 놓을 때 노란 탱탱볼 한 발이 발사되고 몸이 앞으로 이동합니다. 차징 중 꼬리의 흔들림은 멈추지 않습니다.
- 기본공격 탄약은 무한이며 재장전이 필요 없습니다. HUD에는 ∞로 표시합니다. 발사 후 재공격 대기와 회복 모션은 0.20초입니다(기존 대기 0.65초, 회복 모션 0.42초).
- 저학년은 약 0.85m 상승해 잠깐 체공한 뒤 1.1초에 발사합니다. 상승·체공 구간인 0.167–1.2초 동안만 넉백을 막습니다. 피해·기절 면역은 아니며 천장 충돌도 유지합니다. 탄환은 벽·바닥·플레이어 충돌을 합산해 6회 반사하고, 다음 충돌에서 소멸합니다. 다른 적에게 자동 유도하지 않습니다. 벽에 반사되어 돌아온 탄환은 같은 적을 다시 맞힐 수 있습니다. 아군 몸에서도 반사하지만 아군 피해는 없습니다.
- 고학년은 0.2초에 손의 무기를 숨기고, 0.95초부터 앞에 거대 새총을 등장·확대시킵니다. 양손이 줄의 주머니를 당기고 2.5초에 장전된 짱돌을 발사합니다. 이후 새총이 줄어들며 오른손에 돌아옵니다. 1인칭도 양손을 같은 줄의 접점에 맞춥니다.
- 짱돌은 착탄 시 돌 파편과 확산 충격 효과를 냅니다. 기본 피해 80, 반경 4.5m, 기절 3초이며 기존 피해 보정·보호·벽 차폐 규칙을 따릅니다. 아군은 피해와 기절을 받지 않습니다.
- 짱돌 속도는 40m/s, 중력은 1.25m/s²입니다. 평지에서 수평 조준 시 약 60.6m를 날아가며 벽·적과 먼저 충돌하면 그 자리에서 폭발합니다. 날아가는 돌의 크기는 최초 버전의 45%, 충돌 반경은 0.30m로 줄였습니다.
- 새총의 나무 프레임은 고정하고 별도로 만든 고무줄·가죽 주머니만 당깁니다. 고학년에서는 주머니를 위쪽 빈 공간으로 0.085m 올리고, 장전 돌을 더 작게 배치합니다. 프레임과 주머니 사이에 잘못 붙어 있던 면도 분리했습니다. 일반/고학년 당김 모프를 나눠 줄의 단면이 찢어지지 않도록 했습니다.

## 원작 데이터 및 구현

보관된 `assets/references/butter-motion-reference.skel`의 `Attack1_1`(1.5초), `Skill1_1`(2.333초), `Ultimate1_1`(3.933초)를 30Hz로 추출했습니다. 저학년 1.1초와 고학년 2.5초의 원본 Event/SFX 시점을 사용합니다. 기본공격은 원본 19프레임에서 차징 자세를 유지하고, 버튼을 놓으면 20프레임 이후 회복 동작을 재생합니다.

`scripts/extract_butter_skills.cjs` → `assets/characters/skill/butter.json`; `scripts/bake_butter_skills.py` → Blender/FBX의 531–576, 579–649, 652–770프레임. 기존 0–528프레임과 메시 좌표는 보존하며, 기존 꼬리 표면 1,357개 정점의 가중치만 Tail 뼈에 연결합니다. 차징 중 꼬리는 정지된 공격 프레임과 독립적으로 갱신합니다.

전투 수치와 상태는 `src/butter_skill.rs`, 실제 체공은 `src/movement.rs`, 무기·손·효과는 `src/presentation/butter_fx.rs` 및 기존 캐릭터/1인칭/탄환 렌더러에 있습니다. 상태와 효과 나이는 기존 패킷의 여유 비트에 실어 패킷 크기를 늘리지 않습니다. 구버전의 버터 즉시 발사 상태와 혼용하지 않도록 프로토콜 식별자를 갱신했습니다.

## 재현

```powershell
node scripts/extract_butter_skills.cjs
& 'C:\Program Files\Blender Foundation\Blender 5.3\blender.exe' --background --python-exit-code 1 --python scripts/bake_butter_skills.py
cargo test --no-default-features --lib butter
cargo test --no-default-features --test combat butter
cargo build --bin tsb-review
target\debug\tsb-review.exe --butter-skill-review
```

렌더 검증은 기본/차징/발사/체공/무기 숨김/거대화/회복을 1·3인칭으로 총 24장 저장합니다. 발사 이후 장면은 실제 전투 시뮬레이션의 짱돌과 착탄 위치를 사용합니다. 캡처는 `artifacts/preview-butter-skills-*`, 원본 추출·베이크 보존 검증과 실행 로그는 `artifacts/butter-skills/`에 있습니다.

새총 메시 보정은 `scripts/fix_butter_slingshot.py`, 관통 거리 검사와 독립 렌더는 `scripts/verify_butter_slingshot.py`로 재현합니다. 당김 진행도 101개 지점에서 장전 돌의 경계구와 고정 프레임 사이에 최소 0.014m의 간격이 남는지 확인합니다.

## 검증 결과

- 버터 전투·이동·중단·원본 이벤트·원거리 탄도 테스트 12개와 패킷 테스트 2개 통과. 35m 적 명중·기절, 수평 발사 60.56m 착탄, 8m 앞 벽 차단을 검증했습니다. 최초 구현에서 전투 통합 테스트 35개 및 실제 로컬 UDP 궁극기 동기화 테스트도 통과했습니다.
- Blender 검증에서 기존 프레임·메시 좌표 보존, 꼬리 1,357개 정점의 정규화된 가중치와 정점당 최대 4개 뼈 제한, 차징/발사 시 무게중심 이동을 확인했습니다.
- 최초 구현의 전체 headless 회귀 실행은 421개 통과, 3개 실패였습니다. 실패는 버터를 사용하지 않는 `ghost_phase`의 벽 내부 캐릭터 교체 1개와 `roster`의 코미 즉시 충격파 가정 2개입니다. 별도 작업 영역의 규칙을 이 변경에서 수정하지 않았습니다.
- `cargo build --bin tsb-review` 성공. 최종 1·3인칭 24장 캡처와 거대화 시작·중간·최대 당김 단계의 양손 접점 검사를 통과했습니다. 프레임과 장전 돌의 분리 검사는 `artifacts/butter-skills/slingshot-fix/clearance.json`, 원거리 탄도 테스트는 `artifacts/butter-skills/range-tests.log`에 기록했습니다.
