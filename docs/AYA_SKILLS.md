# 아야: 싸락나비 / 만개설화

- 저장된 `assets/references/aya-motion-reference.skel`의 `Skill1_1`(94f), `Ultimate1_1`(110f)을 네이티브 30fps로 샘플링한다. 손·몸통·루트·치마 4개 체인의 원본 곡선을 `assets/characters/skill/aya.json`에 보관한다.
- FBX 타임라인: 저학년 558–652, 고학년 655–765. 기본공격·등장·춤 등 555f까지의 기존 키와 원본 메시 좌표는 보존한다.
- 치마에 8방향 × 2단, 총 16개 `AyaSkirt` 관절을 추가했다. 치맛자락 5,958개 정점을 연속 가중치로 연결하고, 원본 치마 곡선에 끝단 지연을 더한다. 얼굴·머리카락·손은 치마 가중치에서 제외한다.
- 고학년은 양산을 띄우고 양팔을 벌리는 동작이다. 몸 모션과 별도로 1인칭 양손에도 동작을 적용한다.
- `assets/effects/aya-butterfly-concept.png`는 내장 이미지 생성 도구로 그린 모델링 참고도다. 프롬프트는 같은 폴더의 `aya-butterfly-prompt.txt`에 보관했다.
- `aya-effects.blend` / `aya-effects.glb`: 보라색 외곽선과 푸른 날개맥의 나비, 흰 꽃, 반투명 육각 얼음 감옥. 게임에서는 동일한 모델 정점인 `aya-effects-mesh.json`을 읽는다. 나비 양쪽 날개는 독립적으로 펄럭인다.

## 저학년: 싸락나비

1. 1.30초(39f)에 나비 5마리를 좁은 부채꼴로 발사한다. 시전 전에는 작은 나비들이 주변에 모인다.
2. 나비는 14m/s로 날아가며 1.25초 뒤 출발점 방향으로 돌아온다. 적을 관통하며, 각 적은 한 마리의 왕복 각 경로에서 한 번씩 타격된다.
3. 유효 적중마다 피해 6, 저학년 쿨타임 1초 환급. 같은 적의 귀환 경로 재적중도 새 적중으로 계산한다. 무적·아군·벽 충돌은 환급하지 않는다. 쿨타임은 0 미만으로 내려가지 않는다.
4. **약화**: 4초간 주는 피해량 20% 감소. 일반공격·저학년·고학년 모두 적용한다. 재적중은 지속 시간을 갱신하고 감소율은 중첩하지 않는다. 수면의 기존 디버프 면역 규칙은 유지한다.
5. 약화된 캐릭터의 실제 스키닝 메시를 따라 보라색 이중 테두리가 빛난다. 벽 뒤로 투시하지 않는다.

## 고학년: 만개설화

- 시전부터 아야 주변 반경 12m에 눈이 내린다. 범위에 흰 꽃 36송이가 순차적으로 피어나며 연출은 총 5.5초 유지된다.
- **팔 벌림 시점 1.90초(57f)**에 범위 안에서 시야가 통하는 적에게 피해 35와 **동상 3초**를 적용한다. 아군·벽 뒤·스폰 보호·무적·수면 면역·지하 상태는 동상 대상에서 제외한다.
- 동상은 기존 `frost` 지속 피해와 분리된 `frozen` 상태다. 피해를 계속 받을 수 있지만 이동, 점프, 앉기, 기본공격, 재장전, 저학년, 고학년, 종족 스킬, 춤, 인사, 시점 회전이 차단된다. 진행 중 공격·시전은 중단된다.
- 외부에서는 얼음 감옥, 대상의 1인칭 화면에서는 정지된 얼음 결정 무늬와 **동상** 표시가 보인다. 밀치기나 포털 이동으로 감옥 밖으로 밀려나지 않는다. 유령의 벽 통과 종료 처리는 동상 해제 뒤에 진행한다.
- 상태 종료, 사망, 부활 시 입력 잠금과 얼음 표시가 해제된다. 메뉴·채팅 같은 게임 외 UI의 접근은 유지한다.

## 동기화와 검증

스킬 단계·시전 시계는 캐릭터별 기존 패킷 슬롯을 재사용한다. 동상 잔여 시간은 기존 예약 바이트에 60Hz 틱으로 넣는다. 눈 정원의 나이는 투사체 헤딩의 여유 비트에 20Hz로 전송한다. 12인 스냅샷과 투사체 96개 패킷은 1,200바이트 한도를 유지한다. 피해·환급·동상 판정은 서버에서만 실행하며 클라이언트는 이동/시계만 예측한다.

재생성:

```powershell
node scripts/extract_aya_skills.cjs
blender --background --python-exit-code 1 --python scripts/bake_aya_skills.py
blender --background --python-exit-code 1 --python scripts/model_aya_effects.py
cargo test --no-default-features --test aya_skill
cargo test --no-default-features aya --lib
cargo run --bin tsb-review -- --aya-skill-review --solo --no-voice
```

검증 캡처는 `artifacts/preview-aya-skills-*.png`, 베이크 검증 정보와 실행 로그는 `artifacts/aya-skills/`에 저장한다. 모델 재생성은 해당 폴더의 `before/` 기준본을 사용해 중복 관절이 생기지 않게 한다. 밸런스 수치는 `src/aya_skill.rs`의 상수에서 조정한다.

### 확인한 결과

- 아야 전용 게임 규칙 테스트 5개, 아야 필터의 라이브러리/UDP 테스트 7개 통과. 다섯 나비의 왕복 환급, 모든 피해 분류의 약화, 동상 중 회전·이동·공격·예측 차단, 발동 직전 중단과 발동 후 눈 유지, 기존/후발 참가자 동기화를 검증했다.
- 실제 게임 렌더러로 3인칭/1인칭 모션과 효과 10장 캡처. 고학년 발동 구간에 양손이 어깨 높이로 벌어지는지, 양산이 머리 위에 떠 있는지 확인한다.
- 치마 가중치 합과 기존 키/정점 보존 검사 통과. 여섯 프레임에서 치마 관절만으로 발생한 변형은 최대 0.070–0.290m다.
- 전체 회귀 실행에서 유령의 벽 안 캐릭터 교체 테스트 1개가 `Locked` 대신 `PositionFull`을 반환했다. 현재 공유 작업 공간의 포지션 배치 검사와 관련된 별도 실패로 기록했다. 해당 실패 이후의 나머지 테스트 묶음은 별도로 실행해 통과했다.
- 실행 중인 기본 `tsb.exe`는 교체하지 않았다. 최신 코드는 별도 `target/debug/tsb-review.exe`로 빌드했다. 검증 플래그 없이 실행하면 일반 게임으로 사용할 수 있다.
