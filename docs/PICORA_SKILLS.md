`docs/BASIC_ATTACK_MOTIONS.md`와 동일한 `assets/references/picora-motion-reference.skel`을 사용한다. 보관 원본의 SHA-256은 `7a3e137f6f12d33ffa8eef65871001d1492c31f0876df230e6347c9d33e93c3c`다. Spine 런타임으로 곡선과 IK를 평가한 30Hz 손·관절·몸 이동 표본은 `assets/characters/skill/picora.json`, 원본 이벤트 목록은 `artifacts/picora-skills/reference/source.json`에 있다. 원작 수치를 복제하는 작업이 아니라 요청한 FPS 효과로 각색한 구현이다.

기본 마력탄은 속도 24m/s, 기본 피해 17, 간격 0.5초, 탄창 18발이다. 공격 속도 변화는 기존 공격 시계를 따른다. 네 번째 공격의 튕김을 없애 모든 일반 공격에 같은 파란 마력탄을 사용한다. 탄의 첫 화면은 애니메이션이 적용된 지팡이 머리의 공통 발사점에서 시작하고 0.10초 동안 서버의 조준 궤적으로 합류한다. 발사 뒤 지팡이를 움직여도 이미 발사된 탄은 끌려가지 않는다.

E/Q는 조준선과 교차하는 18m 내 살아 있는 아군 한 명을 선택한다. 자기 자신, 적, 잠복한 아군, 벽 뒤의 아군은 대상이 아니다. 대상이 없으면 쿨타임·궁극기 게이지를 소모하지 않는다. 시전 시작 때 대상을 고정하고 발동 때 생존·거리·가림을 다시 확인한다. 도중에 시점을 돌려도 다른 아군에게 옮겨가지 않는다. 기절·동결·수면·변이·도발·사망·캐릭터 교체는 시전을 취소한다.

E는 기본 44 회복과 4초간 모든 받는 피해 25% 감소를 준다. 기존 치유 보정과 실제 치유량 통계를 적용하고, 같은 종류의 25% 저항과 곱중첩하지 않는다. 스티커는 흰 테두리와 노란 하트가 있는 보라색 별 모양이며 대상의 오른쪽 소매를 따라간다. 대상 본인의 1인칭 소매에도 표시한다. 만료·사망·교체 시 제거한다. E 기본 쿨타임 11초, 마녀 보정 적용 후 10.45초다.

Q는 8초간 최대 체력을 120에서 240으로 늘린다. 적용·만료 때 현재 체력 비율을 유지한다. 예를 들어 60/120은 120/240이 되고, 종료 시 191/240은 96/120으로 돌아온다. 회복은 확대된 최대치까지 가능하다. 재적용은 지속시간만 갱신하며 체력과 최대치를 다시 곱하지 않는다. 체력바·이름표·저체력 경고·최대 체력 비례 피해도 현재 최대치를 사용한다. 기존 보호막·주변 도발·종료 회복은 제거했다.

Q의 3인칭 전신은 원본 도약과 착지 동작을 재생한다. 실제 충돌 위치와 카메라는 점프시키지 않으며, 1인칭 손·지팡이 이동도 없다. E/Q 모두 발동 때 지팡이 머리에서 0.34초간 섬광이 나고, 0.24초간 대상에게 가는 마력 광선이 나타난다. E는 부착된 소매 스티커, Q는 대상의 몸통으로 이어진다. 지정된 아군의 실제 스킨 메시 외곽에 무지개색과 흰 반짝임이 흐른다. 테두리는 벽 뒤로 비치지 않는다.

1인칭 지팡이 배율은 0.72에서 1.20으로 약 1.67배 확대했다. 손잡이를 기준으로 크기를 조정하고 카메라 기준 위치를 `(-0.50, -0.36, 0.70)`으로 옮겨 갈고리 머리가 화면 안에 들어오도록 한다. 기본공격·E·Q는 1인칭과 3인칭 모두 같은 지팡이 머리 소켓을 사용하며, 소켓은 크기·회전·파지 애니메이션을 따라간다.

서버가 발동·회복·버프를 판정한다. 시전 단계·시각·대상과 대상별 버프를 스냅샷에 보존하여 관전자와 사망 재생에도 연결한다. 8비트 체력과 4비트 버프 타이머 두 개를 기존 체력 필드에 넣어 패킷 크기를 유지한다. 버프 만료는 서버 스냅샷이 결정하며 표시용 타이머는 올림 양자화된다. 프로토콜은 `TSBM`이므로 참가자는 같은 빌드를 사용해야 한다.

## 재생성 및 검증

1. `node scripts/extract_picora_skills.cjs`
2. Blender 백그라운드에서 `scripts/bake_picora_skills.py` 실행.
3. `cargo test --offline --no-default-features --test picora_skill`
4. `cargo test --offline --no-default-features --lib picora_tests`
5. `cargo build --offline --no-default-features --features desktop --bin tsb-review`
6. `Review.cmd --solo --picora-skill-review --lan` 또는 `target/debug/tsb-review.exe --solo --picora-skill-review --lan`

베이크는 기존 메시 좌표와 0–528프레임 키를 보존하고 E 531–597, Q 600–660을 추가한다. 변경 전 모델은 `artifacts/picora-skills/before`, 보존 검사 결과는 `artifacts/picora-skills/bake-verification.json`에 있다. GPU 검증은 전신·1인칭 13개 화면과 지팡이 파지 오차, E/Q 광선의 시작·도착점, 1인칭 Q의 고정 시점을 검사한다. 화면은 `artifacts/preview-picora-skills-*`에 저장한다. `--solo --picora-muzzle-review --lan`은 실제 기본공격을 양 시점에서 발사하여 지팡이 발사점 오차를 검사하고, `--solo --weapon-review --picora-only --lan`은 대기·공격·재장전 파지를 검사한다. 지팡이 수정 검증 로그는 `artifacts/picora-staff/`에 저장한다.

## 검증 결과 — 2026-11-20

- 피코라 게임플레이 8개와 네트워크 2개 테스트 통과. 최대 체력 만료 때 정령 보호막 상한도 복구되는지 확인했다.
- 로컬 UDP 통신을 허용한 환경에서 라이브러리 테스트 196개 통과. 공통 전투 34개와 선택 4개도 통과했다.
- 데스크톱/LAN 검증 빌드 성공. GPU 검증 12개 장면을 저장하고 정상 종료했다. 파란 탄, E 소매 부착, Q 도약·무지개 테두리, 1인칭 Q 고정과 지팡이 섬광을 확인했다.
- 기존 애니메이션 키와 메시 좌표 보존 검사 통과. FBX의 SHA-256이 manifest와 일치하고 보관 원본의 SHA-256도 조사 기록과 일치한다.

전체 통합 테스트가 모두 통과한 것은 아니다. 별도 캐릭터 작업과 관련된 기존 에르핀 `erpin_fires_four_bombs_and_charge_cannot_cross_walls` 기대값 실패를 확인하여 공통 전투 재검증에서는 제외했다. 코미 충격파 거리 기대값을 검사하는 `dragon_resists_shockwave_and_witch_cooldown_applies_without_repeat_cast`, `shockwave_respects_spawn_protection_cover_and_swept_collision` 두 테스트도 실패했다. 이 세 항목은 피코라 변경 범위 밖으로 남겨 두었다. 세부 결과는 `artifacts/picora-skills/integration-tests.log`와 관련 테스트 로그에 있다.
