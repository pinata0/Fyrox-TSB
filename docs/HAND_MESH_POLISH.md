# 손·손목·소매 메시 정리

## 원작 비율의 네 손가락·두 마디 / 2026-11-20

현재 모델은 엄지를 포함해 한 손에 **4개**, 각 손가락에 **2개 본**을 사용한다. 검지·중지·바깥 손가락(Pinky)과 엄지만 남기고 약지 및 세 번째 마디 본을 제거했다. 15명 양손의 활성 손가락 본은 총 240개다. 아래의 다섯 손가락·세 관절 설명은 이전 판의 기록이다.

일반 손가락의 기준 길이는 0.070m에서 0.043m로 약 39% 줄이고 지름은 0.0162m에서 0.022m로 약 36% 넓혔다. 캐릭터별 기존 손 크기 배율을 유지하며, 엄지도 짧고 둥글게 만든다. 하나로 연결된 손 표면에 엄지와 나머지 세 손가락의 틈을 만들고, 두 마디 가중치와 파지 각도를 다시 계산한다. 손바닥 소켓과 파지 반경은 유지한다.

`scripts/cartoon_hands.py`가 현재 모델의 최초 스냅샷을 `artifacts/cartoon-hands/before/`에 보관하고, 검토용 모델을 같은 폴더의 `characters/`에 생성한다. 얼굴·모프·몸·소매·동료 메시의 정점, 면, UV, 활성 가중치 해시를 보존 검사한다. 새 손만 별도의 `<이름>-cartoon-hands.png` 텍스처를 사용한다.

재현 순서는 `cartoon_hands.py` → `verify_cartoon_hands.py` → `publish_cartoon_hands.ps1`다. 앞의 두 스크립트는 Blender 백그라운드에서 실행하고 마지막 PowerShell 스크립트는 파일 적용·매니페스트·모프 재생성을 수행한다. 검증은 연결된 닫힌 표면, 세 개의 일반 손가락 실루엣, 엄지를 포함한 여덟 본, 실제 두 번째 마디의 손잡이 접촉, 피부 늘어남 및 FBX 재가져오기를 확인한다. `review_cartoon_hands.py`는 변경 전·펼친 손·쥔 손을 실제 모델에서 렌더링한다. 최초 스냅샷을 재사용하므로 이후 다른 모델 수정까지 반영하려면 새 검토 폴더로 스냅샷을 분리해야 한다.

게임의 `hand_grip.rs`도 네 손가락·두 마디 스키마를 검사한다. 수정 전 실행 파일은 이전 15개 관절을 요구하므로 새로 빌드한 실행 파일을 사용한다. `Play.cmd`로 이 수정본을 실행한다.

15명 30개 손의 독립 메시·FBX 검사, 무기/외부 시점 102개 화면 및 인사 45개 화면을 확인했다. 인사 검사는 캐릭터마다 109틱의 연속성과 화면 내 손가락 위치도 검사한다. 검사 도중 발견한 기존 빈손·스킬 전용 보조손의 오래된 고정 파지 판정은 현재 캐릭터 동작에 맞췄다. 결과와 최종 파일 해시는 `artifacts/cartoon-hands/delivery-report.json`, 전후 렌더는 `hand-comparison.png`, 게임 화면은 같은 폴더의 `screenshots/`에 있다.

## 이전 손 메시 정리 기록

이전 HandGrip 판의 손가락 관절과 손바닥 접점은 유지하면서, 거친 손 표면과 손등을 덮던 소매를 새 메시로 교체했다. 15명 양손에 분리된 네 손가락과 엄지, 매끈한 손바닥·손목, 폭을 줄인 소매와 둥근 소매 끝을 적용했다.

## 형태와 파지

- 손은 하나로 이어진 닫힌 표면이다. 손가락 사이와 엄지 밑의 연결부를 부드럽게 정리하고, 소매 절단면과 미세한 틈을 막았다.
- 엄지는 옆에서 돌아오는 동작으로 손잡이를 받친다. 검지·약지·새끼손가락은 길이에 맞는 굽힘 각도를 사용해 손잡이 안으로 파고들지 않도록 했다.
- 손목이 소매 밖으로 드러나도록 소매 끝을 뒤로 옮겼다. 캐릭터별 색과 테두리를 유지하고, 에르핀의 푸른 마름모 장식을 다시 배치했다.
- 손과 소매에는 옅은 음영·접촉 음영을 구워 게임 조명에서도 손가락과 소매의 둥근 형태가 보이도록 했다.
- 1인칭은 손잡이 축을 유지한 채 화면 아래의 해당 팔 방향에서 접근한다. 1인칭 전용 소매는 화면 밖까지 이어지며 외부 시점에서는 숨긴다. 외부 시점에는 원래 팔 길이에 맞춘 닫힌 소매를 사용한다.

얼굴 표정이 움직이는 정점과 주변 두 겹의 면은 교체 범위에서 보호한다. 본체 정점 위치, 23개 표정 모프의 좌표 및 해당 얼굴 면을 원본과 대조한다. 기존 11개 모션과 동료·무기 에셋도 유지한다.

## 파일과 재생성

게임·편집 에셋은 `assets/characters/`에 있다. `<이름>_RefinedHand.L/R`, `RefinedSleeve.L/R`, `RefinedViewSleeve.L/R`가 새 메시이고, `<이름>-refined-arms.png`는 구운 텍스처다. 이전 HandGrip 모델은 `artifacts/hand-mesh-polish/before/`에 보존한다.

작업은 `artifacts/hand-mesh-polish/characters/`에서 진행하며 아래 순서로 다시 만들 수 있다. 마지막에 검증된 파일을 게임 에셋으로 적용한다.

1. `scripts/refine_character_hands.py` — 원본 보존, 새 메시·관절 기준 생성, 기존 팔 면 정리.
2. `scripts/bake_refined_hand_textures.py` — UV와 표면 음영 텍스처 생성.
3. `scripts/seal_refined_surfaces.py` — 축소 과정의 미세한 틈 용접·폐쇄, 스킨 가중치 정규화.
4. `scripts/fit_refined_grips.py` — 손가락별 파지와 엄지 대립 동작, 중립 얼굴 값 저장.
5. `scripts/export_meshy_morphs.py` — 변경된 FBX의 표정 모프 연결 데이터 생성.
6. `scripts/verify_refined_hands.py`, `scripts/verify_meshy_assets.py` — 표면·파지·얼굴 보존·모션·FBX 검사.
7. `scripts/publish_refined_hands.py` — 검사된 모델 적용과 텍스처 경로 정리. 적용 후 게임용 모프 연결 데이터를 한 번 더 생성한다.

닫힌 손 검사는 실제 게임과 같이 손 본 기준의 회전 축을 사용한다. 각 손가락의 가시 정점, 손잡이 표면과의 거리, 관통량, 표면 늘어남을 확인한다. 검사 기준 원통에서 접점은 3mm 이내, 손가락 관통량의 99백분위는 2mm 미만이어야 한다. 손·소매에는 열린 경계나 비정상 연결이 없어야 한다.

실행 파일: `release/TSB-Multiplayer-PolishedHands.exe`. 검증과 파일 해시: `artifacts/hand-mesh-polish/validation-report.json`.

## 1인칭 무기 거리·방향 보정

일반 무기의 카메라 기준 거리를 0.80m에서 0.56m로 줄이고 오른쪽으로 옮겼다. 손잡이 위치는 `(-0.44, -0.28, 0.56)`이며 카메라 좌표의 -X가 화면 오른쪽이다. 무기 크기와 공격 모션은 유지하고 원래 손바닥 접점이 변경된 무기 위치를 따라간다. 총구 섬광도 새 위치에 맞춰 이동한다. 비비는 별도의 부유 무기·양손 배치를 사용한다.

시온의 가져온 총 모델은 총구가 -Z를 향해 앞뒤가 뒤집혀 있었다. 무기 메시만 Y축으로 180도 돌리고 방아쇠 손잡이를 원점에 다시 맞췄다. 오른손은 방아쇠 손잡이를, 왼손은 앞쪽 몸통을 받치며 스코프가 위를 향한다. 동일한 무기 모델을 쓰는 외부 시점에도 방향 보정이 적용된다.

변경 전 코드·화면과 검증 자료는 `artifacts/viewmodel-position/`에 보관한다.

`--weapon-review --auto-start --hud-review-small`의 102개 GPU 캡처가 종료 코드 0으로 통과했다. 15명의 대기·공격·재장전, 화면 전환과 외부 시점, 손바닥 접점 오차 1mm 미만을 확인했다. 전체 대기·공격·재장전 화면 모음과 시온의 전후 비교는 같은 검증 폴더에 있다. 수정본은 `release/TSB-Multiplayer-WeaponView.exe`이다.

검증용 배포 폴더는 동시에 진행되는 작업의 변경을 피하도록 고정했다. 포함된 새 비비 FBX는 텍스처 파일명이 폴더 경로로 저장되어 있어 복사본의 경로를 고쳤고, 실제 FBX에서 표정 연결 데이터를 다시 생성했다. 이 보정은 `fix_packaged_vivi_paths.py`와 `stage-morphs.log`에 기록되어 있다.

## 전체 1인칭 동작의 손·소매 확대 / 2026-11-20

화면용 손과 소매를 기존의 1.65배로 키웠다. `first_person.rs`의 공통 배율을 기본 파지·공격·재장전·인사, 에르핀의 먹기, 이드·리뉴아의 빈손 동작, 아야·힐데·나이아의 스킬과 궁극기에 적용한다. 확대 후 손바닥을 기존 접점에 다시 맞추므로 무기와 손이 떨어지지 않는다. 힐데의 스킬용 소매 두께도 같은 배율을 사용하며, 나이아 E의 추가 확대는 공통 배율 위에 적용한다. 화면에는 기존의 분리된 손과 1인칭용 소매를 사용하고, 전신 모델과 월드 무기 크기는 유지한다. 검증 자료는 `artifacts/first-person-framing/`에 보관한다.

모든 동작을 적용한 뒤 주손 소매는 화면 오른쪽 아래, 보조손 소매는 왼쪽 아래에서 들어오도록 팔 방향을 보정한다. 손바닥의 위치와 회전은 보존하며, 인사·스킬·재장전으로 손이 움직여도 소매의 진입 방향을 유지한다. 화면용 메시에는 전신 모델의 바운딩 박스로 인한 잘못된 프러스텀 컬링을 적용하지 않는다. `--weapon-review --first-person-framing-only --solo --auto-start --hud-review-small`로 15명의 대기·공격·재장전 45개 화면과 소매 방향·손잡이 접점을 확인한다.

확대된 팔로 인사할 때 손이 화면 밖으로 나가지 않도록 손바닥을 카메라 안쪽으로 부드럽게 이동시킨다. 이드와 리뉴아는 빈손 기본 자세에서 출발하고 복귀한다. `--greeting-review --first-person-framing-only`는 전원 인사·복귀 45개 화면과 캐릭터별 109틱의 연속성, 손가락 관절의 화면 내 위치를 검사한다. 수정본은 `Play.cmd`로 실행한다.

## 마요의 손등이 위를 향하는 파지 / 2026-11-20

마요는 발사관을 위에서 감싸도록 손바닥 소켓의 축을 맞췄다. 1인칭의 공통 파지 회전 보정 대신 이 방향을 유지하며, 외부 시점에도 같은 방향을 적용한다. 손바닥 접점과 오른쪽 아래에서 들어오는 소매 배치는 기존 보정을 따른다.

발사관의 긴 쪽은 손 앞으로 향하고 뒤쪽 끝은 손 바로 뒤에 오도록 모델을 이동했다. 관의 중심축을 손바닥 접점에 맞추고, 두께는 마요의 `hands.json`에 기록된 손가락 파지 반경에 맞춘다. 1인칭은 확대된 손 크기까지 반영하므로 손가락이 관 안에 묻히지 않고 몸통을 감싼다. 발사관 길이와 손등 방향은 유지한다. 이 추가 조정의 화면·손가락 간격 측정·검증 로그는 `artifacts/mayo-grip-forward/`에 보관한다.

`Play.cmd`로 수정 빌드를 실행한다. 재현 검증은 `--weapon-review --mayo-only --solo --auto-start --hud-review-small`이며, 1인칭 대기·공격·재장전과 외부 시점 대기·공격 5개 화면의 손가락 파지·손잡이 접점·소매 방향을 검사한다. `--weapon-side-view`를 추가하면 외부 시점을 옆에서 확인할 수 있다. 검증 로그와 화면은 `artifacts/mayo-grip/`에 보관한다.

## 손 확대와 팔·소매 두께 추가 조정 / 2026-11-20

공통 크기를 1.65배에서 2.2배로 올리고, 화면용 팔 메시의 단면을 관절 가중치에 따라 별도로 1.35배 넓혔다. 직전 버전 대비 손은 약 33%, 팔·소매 두께는 약 80% 커졌다. 손가락과 손바닥 접점, 뼈 길이를 유지하면서 손목에서 넓어진 팔로 부드럽게 이어지고, 표면 법선과 탄젠트도 보정한다. 나이아 E 전용 소매와 힐데의 의료 소매에도 같은 두께 배율을 적용한다. 검증 자료는 `artifacts/first-person-thickness/`에 보관하고, 실행기는 `Play.cmd`를 사용한다.


### 나이아 총구와 아야 1인칭 손잡이

나이아의 기본 공격 물방울은 애니메이션이 적용된 물총 총구에서 시작하고, 0.1초 동안 기존 탄도로 합류한다. 발사 순간 위치를 저장하므로 발사 후 조준·반동에 끌려가지 않으며, 총구 크기로 시작해 원래 물방울 크기로 돌아온다. 피격 판정과 네트워크 탄도는 그대로 사용한다.

아야는 1인칭 우산 메시의 실제 손잡이를 손바닥 접점에 맞추고, 기울어진 자루를 손가락의 파지 축에 정렬한다. 접기와 칼날 변형에도 같은 보정을 적용한다.

재현: `cargo run --release --locked --bin tsb-review -- --solo --auto-start --naia-muzzle-review --lan`, `cargo run --release --locked --bin tsb-review -- --solo --auto-start --weapon-review --aya-only --lan`. 발사 보간 테스트는 `cargo test --release --locked --bin tsb launch_tests`로 실행한다.

### 마요 1인칭 손바닥 방향과 대롱 아이콘 / 2026-11-21
