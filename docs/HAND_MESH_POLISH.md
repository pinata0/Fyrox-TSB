# 손·손목·소매 메시 정리

이전 HandGrip 판의 손가락 관절과 손바닥 접점은 유지하면서, 거친 손 표면과 손등을 덮던 소매를 새 메시로 교체했다. 15명 양손에 분리된 네 손가락과 엄지, 매끈한 손바닥·손목, 폭을 줄인 소매와 둥근 소매 끝을 적용했다.

## 형태와 파지

- 손은 하나로 이어진 닫힌 표면이다. 손가락 사이와 엄지 밑의 연결부를 부드럽게 정리하고, 소매 절단면과 미세한 틈을 막았다.
- 엄지는 옆에서 돌아오는 동작으로 손잡이를 받친다. 검지·약지·새끼손가락은 길이에 맞는 굽힘 각도를 사용해 손잡이 안으로 파고들지 않도록 했다.
- 손목이 소매 밖으로 드러나도록 소매 끝을 뒤로 옮겼다. 캐릭터별 색과 테두리를 유지하고, 에르핀의 푸른 마름모 장식을 다시 배치했다.
- 손과 소매에는 옅은 음영·접촉 음영을 구워 게임 조명에서도 손가락과 소매의 둥근 형태가 보이도록 했다.
- 1인칭은 손잡이 축을 유지한 채 화면 아래의 해당 팔 방향에서 접근한다. 1인칭 전용 소매는 화면 밖까지 이어지며 외부 시점에서는 숨긴다. 외부 시점에는 원래 팔 길이에 맞춘 닫힌 소매를 사용한다.

얼굴 표정이 움직이는 정점과 주변 두 겹의 면은 교체 범위에서 보호한다. 본체 정점 위치, 23개 표정 모프의 좌표 및 해당 얼굴 면을 원본과 대조한다. 기존 11개 모션과 동료·무기 에셋도 유지한다.

## 파일과 재생성

게임·편집 에셋은 `assets/characters/`에 있다. `<이름>_RefinedHand.L/R`, `RefinedSleeve.L/R`, `RefinedViewSleeve.L/R`가 새 메시이고, `<이름>-refined-arms.png`는 구운 텍스처다. 이전 HandGrip 모델은 `artifacts/hand-mesh-polish/before/`에 보존한다.

작업은 `artifacts/hand-mesh-polish/characters/`에서 진행하며 아래 순서로 다시 만들 수 있다. 마지막에 검증된 파일을 게임 에셋으로 적용한다.

1. `scripts/refine_character_hands.py` — 원본 보존, 새 메시·관절 기준 생성, 기존 팔 면 정리.
2. `scripts/bake_refined_hand_textures.py` — UV와 표면 음영 텍스처 생성.
3. `scripts/seal_refined_surfaces.py` — 축소 과정의 미세한 틈 용접·폐쇄, 스킨 가중치 정규화.
4. `scripts/fit_refined_grips.py` — 손가락별 파지와 엄지 대립 동작, 중립 얼굴 값 저장.
5. `scripts/export_meshy_morphs.py` — 변경된 FBX의 표정 모프 연결 데이터 생성.
6. `scripts/verify_refined_hands.py`, `scripts/verify_meshy_assets.py` — 표면·파지·얼굴 보존·모션·FBX 검사.
7. `scripts/publish_refined_hands.py` — 검사된 모델 적용과 텍스처 경로 정리. 적용 후 게임용 모프 연결 데이터를 한 번 더 생성한다.

닫힌 손 검사는 실제 게임과 같이 손 본 기준의 회전 축을 사용한다. 각 손가락의 가시 정점, 손잡이 표면과의 거리, 관통량, 표면 늘어남을 확인한다. 검사 기준 원통에서 접점은 3mm 이내, 손가락 관통량의 99백분위는 2mm 미만이어야 한다. 손·소매에는 열린 경계나 비정상 연결이 없어야 한다.

실행 파일: `release/TSB-Multiplayer-PolishedHands.exe`. 검증과 파일 해시: `artifacts/hand-mesh-polish/validation-report.json`.

## 1인칭 무기 거리·방향 보정

일반 무기의 카메라 기준 거리를 0.80m에서 0.56m로 줄이고 오른쪽으로 옮겼다. 손잡이 위치는 `(-0.44, -0.28, 0.56)`이며 카메라 좌표의 -X가 화면 오른쪽이다. 무기 크기와 공격 모션은 유지하고 원래 손바닥 접점이 변경된 무기 위치를 따라간다. 총구 섬광도 새 위치에 맞춰 이동한다. 비비는 별도의 부유 무기·양손 배치를 사용한다.

시온의 가져온 총 모델은 총구가 -Z를 향해 앞뒤가 뒤집혀 있었다. 무기 메시만 Y축으로 180도 돌리고 방아쇠 손잡이를 원점에 다시 맞췄다. 오른손은 방아쇠 손잡이를, 왼손은 앞쪽 몸통을 받치며 스코프가 위를 향한다. 동일한 무기 모델을 쓰는 외부 시점에도 방향 보정이 적용된다.

변경 전 코드·화면과 검증 자료는 `artifacts/viewmodel-position/`에 보관한다.

`--weapon-review --auto-start --hud-review-small`의 102개 GPU 캡처가 종료 코드 0으로 통과했다. 15명의 대기·공격·재장전, 화면 전환과 외부 시점, 손바닥 접점 오차 1mm 미만을 확인했다. 전체 대기·공격·재장전 화면 모음과 시온의 전후 비교는 같은 검증 폴더에 있다. 수정본은 `release/TSB-Multiplayer-WeaponView.exe`이다.

검증용 배포 폴더는 동시에 진행되는 작업의 변경을 피하도록 고정했다. 포함된 새 비비 FBX는 텍스처 파일명이 폴더 경로로 저장되어 있어 복사본의 경로를 고쳤고, 실제 FBX에서 표정 연결 데이터를 다시 생성했다. 이 보정은 `fix_packaged_vivi_paths.py`와 `stage-morphs.log`에 기록되어 있다.
