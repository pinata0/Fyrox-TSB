# 시작 크레딧과 로그인 선택

일반 실행은 흰 배경의 EPID Games → DOTG 크레딧을 각 2.6초 동안 페이드 인·아웃한 뒤
로그인 / 회원가입 / 게스트로 로그인하기 화면을 연다. 로고 화면에는 설명과 조작 안내를
표시하지 않으며 클릭·Enter·Esc로 건너뛰지 않고 자동 전환한다. 로딩이나 프레임 지연으로 로고가 생략되지 않는다.
화면 크기와 입력 영역은 같은 배율을 사용하고, Tab·Shift+Tab·방향키·Enter를 지원한다.
사용자 요청에 따라 게스트 설명, 키 조작 안내, 로그인 화면 하단 영문 표기는 표시하지 않는다.

- 로그인/회원가입은 기존 DOTG 웹 인증을 사용한다. `/login` 또는 `/signup`에
  일회성 연결 코드를 포함한 `/play?connect=XXXXXXXX` 복귀 경로를 전달한다.
  웹에서 로그인(가입 시 이메일 인증)과 연결 승인을 마치면 게임이 승인된 프로필을 받아
  자동으로 홈을 연다. 비밀번호와 웹 세션 토큰을 게임에 저장하지 않는다.
- 실패하면 같은 화면에서 재시도, 뒤로, 게스트 선택이 가능하다. 10분 후 연결 코드는 만료된다.
  취소·게스트 선택은 요청 세대를 갱신하고 기기 토큰을 버리므로 늦은 응답이 계정을 덮어쓰지 않는다.
- 게스트는 인증 서버 요청 없이 홈으로 진입한다. 연습 및 EOS/LAN 코드 방 기능은 유지된다.
- 방 선택의 웹 계정 연결 버튼은 제거했다. 게스트의 홈 프로필/소셜은 선택 화면을 다시 열고,
  로그인 상태에서는 기존 프로필/친구 라운지를 연다. 로고는 홈 복귀 시 반복하지 않는다.
- `--auto-start`, 전투·홈·로비 검증, 인증된 `--online-session` 실행은 시작 선택을 건너뛴다.

`src/presentation/startup.rs`가 화면과 상태 전환을, `rooms.rs`가 기존 기기 연결과
응답 취소를 처리한다. `scripts/package_portable.py`는 두 PNG를 배포 파일에 포함한다.
로고 출처는 `assets/ui/startup/SOURCES.md`에 기록했다.

웹사이트의 `safePlayerReturnPath`와 `/play` 로그인 폼도 수정했다. 정확한 8자리
연결 코드만 복귀 URL로 허용하며 로그인·회원가입·이메일 확인 뒤에도 유지한다.
이 웹 소스 수정은 운영 웹사이트 배포 전에는 적용되지 않는다. 기존 배포 서버에서는
게임 화면의 코드를 웹 라운지에 직접 입력하고 연결 승인할 수 있다.

검증: 전체 Rust 회귀 테스트(로컬 UDP 허용 환경), Clippy 경고 금지 검사,
웹 인증 경로 테스트와 TypeScript 검사. `--startup-review`는 두 로고, 선택 화면,
로그인/가입 대기, 960×640 및 1920×800 화면을 GPU로 캡처한다.
스크린샷은 `artifacts/preview-startup-*.png`, 로그는 `artifacts/startup/`에 저장했다.
실제 개인 계정 가입·이메일 인증은 수행하지 않았다.

최종 배포 파일: release/TSB-Multiplayer-Startup.exe. --verify-only 종료 코드 0, 추출 EXE와 두 로고의 SHA-256 일치를 확인했다.
