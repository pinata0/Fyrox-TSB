# DotG 계정·친구·초대 연결

웹사이트의 `/play` 라운지에서 가입·이메일 인증·로그인, 게임 프로필, 친구 요청·수락·삭제·차단, 방 초대를 관리합니다. 기존 동아리원 소개 카드와 관리자 계정 권한은 별도로 유지합니다.

## 현재 실행 방법

1. 웹사이트에 `20261113090000_add_game_social.sql` 마이그레이션과 새 Next.js 코드를 배포합니다. 상세 설정은 웹사이트의 `docs/game-social.md`를 따릅니다.
2. 두 사용자가 `/play`에 가입하고 프로필을 저장합니다. 사용자 ID로 친구 요청을 보내고 상대가 수락합니다.
3. 호스트는 `/play`에서 방을 만들며 다른 PC에서 접속 가능한 주소를 입력합니다. 같은 공유기의 테스트 예시는 `192.168.0.10:28080`입니다.
4. 호스트 파일을 내려받아 다음 명령으로 게임을 실행합니다. 게임은 해당 포트를 열고 서명된 초대를 요구합니다.

```powershell
cargo build --bin tsb
.\scripts\Start-OnlineGame.ps1 -SessionFile "$env:USERPROFILE\Downloads\dotg-host.tsb-session.json"
```

5. 웹사이트 친구 목록에서 친구를 방에 초대합니다. 상대는 초대를 수락한 뒤 참가 파일을 받고 **5분 안에** 같은 실행 도우미로 엽니다.

```powershell
.\scripts\Start-OnlineGame.ps1 -SessionFile "$env:USERPROFILE\Downloads\dotg-join.tsb-session.json"
```

직접 실행도 가능합니다: `tsb.exe --online-session <파일 경로>`. 실행 위치는 `assets`, `data`가 있는 게임 폴더여야 합니다. 호스트 파일은 공유하지 않고 사용 후 삭제합니다. 참가 파일도 비공개로 취급합니다. 이 파일들에는 Supabase 계정 비밀번호·액세스 토큰·관리자 키가 들어가지 않습니다.

홈 화면의 **소셜/프로필**과 우측 친구·프로필 버튼은 웹 라운지를 엽니다. 기본 주소는 `https://www.dotgsince2023.co.kr/play`이며 별도 환경 변수 설정 없이 사용합니다. 로컬 개발 등 다른 웹사이트를 사용하려면 게임 실행 전에 `DOTG_PORTAL_URL`을 지정합니다.

```powershell
$env:DOTG_PORTAL_URL = 'http://localhost:3000/play'
```

`DOTG_PORTAL_URL`은 기본 주소보다 우선하며, 로컬 개발 주소를 제외하고 HTTPS만 허용합니다. 로그인과 프로필 편집은 브라우저에서 진행하고, 다운로드한 참가 파일을 실행할 때 게임 세션에 반영합니다. 게임 내 홈 프로필과 체력 HUD에 인증된 닉네임이 표시되고 다른 참가자에게도 동기화됩니다. 기존 `--join IP:port`, 연습 모드는 유지됩니다.

## 인증·만료

- Auth 계정 ID에 게임 프로필을 연결합니다. 소개 카드 `member_profiles`나 관리자 역할 `profiles.role`을 게임 프로필로 사용하지 않습니다.
- 방은 최대 2시간, 초대는 15분, 발급된 참가권은 최대 5분 유효합니다.
- 참가권에는 방 ID, 계정 ID, 만료 시간, 일회성 ID, 닉네임이 서명됩니다. 호스트는 HMAC-SHA256 서명을 검증하며 위조·만료·다른 방·중복 계정·재사용 참가권을 거부합니다.
- 연결이 끊어졌다면 웹사이트에서 새 참가 파일을 받아 재접속합니다. 같은 파일을 여러 클라이언트나 재접속에 재사용할 수 없습니다.
- 차단·친구 삭제·초대 마감은 **새 참가권 발급을 차단**합니다. 이미 발급된 참가권은 최대 5분의 남은 유효기간이 있고, 이미 접속한 사람을 자동으로 내보내지는 않습니다. 오프라인 호스트 검증 방식의 제한입니다.
- 방의 2시간 만료는 신규 입장을 제한하며 진행 중인 경기를 강제 종료하지 않습니다. 호스트가 게임을 종료하면 경기도 종료됩니다.

## EOS P2P 방

게임의 기본 방 만들기는 EOS P2P입니다. 게임 입력·상태·채팅·보이스 전체가 EOS를 거치며 직접 연결이 어려우면 중계를 사용합니다. 웹 방 목록에서는 EOS 주소를 자동 등록하므로 호스트 IP나 포트 입력이 필요 없습니다. `--lan`으로 실행하면 기존 직접 UDP 방을 만듭니다.

웹에는 `20261113110000_add_game_room_directory.sql`과 `20261113120000_add_eos_p2p_rooms.sql` 마이그레이션 및 새 API를 적용해야 합니다. 게임 설정과 두 PC 점검은 [EOS 설정 안내](eos-setup.md)를 따릅니다.

기존 파일 방식도 `eos_p2p` 전송을 지원합니다. `tsb.exe --eos-host`로 만든 방에서 **코드 복사하기** 버튼으로 코드를 복사해 `/play`의 방 주소에 입력하고, 게임을 종료한 뒤 내려받은 호스트 파일로 다시 실행합니다. 호스트 파일의 EOS ID가 현재 PC의 로그인 ID와 다르면 거절합니다. 참가자는 서명된 참가 파일을 사용하며, 만료·재사용·다른 방·중복 계정 검사는 유지됩니다. 인증 없는 일반 코드 방은 서명된 초대 참가를 받아들이지 않습니다.

EOS Device ID는 DotG 계정 증명이 아닙니다. EOS는 전송 상대를 식별하고, 웹 계정과 방 입장 권한은 기존 서명된 참가권이 증명합니다. 공개 방 목록은 실제 EOS 주소·호스트 키를 공개하지 않습니다. 영구적인 계정 연결이나 실시간 차단 강제 퇴장은 이 변경에 포함하지 않습니다.

## 검증

`cargo test --no-default-features`는 게임 규칙과 UDP 참가 인증을 검증합니다. 로컬 소켓이 허용된 환경에서 실행해야 합니다. `cargo test --bin tsb presentation::home::tests`는 홈 버튼 영역을 검증합니다.
웹사이트의 `pnpm test:game-social`은 독립된 PGlite PostgreSQL에서 실제 마이그레이션, 사용자별 권한, 친구 요청, 차단, 초대, HMAC 호환성을 검증합니다. 운영 Supabase 데이터에는 접근하지 않습니다.
