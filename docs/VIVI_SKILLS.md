# 비비 모션과 수은 창

2026-11-20. 보관된 전투 Spine의 `Idle`, `Attack1_1`, `Skill1_1`, `Ultimate1_1`을 30Hz로 평가하여 현재 비비 모델에 적용했다. 팔과 무기의 깊이, 1인칭 가시성, 수은 창 형태는 3D 게임에 맞춰 각색했다.

## 동작

- 대기: 원작 1.333초 날개 주기를 반복한다. 날개 4본과 치마 6본을 추가했으며 등 뒤의 수은 칼날 네 개는 위를 향해 펼쳐진다.
- 좌클릭: `Attack1_1`의 앞 0.8초는 좌→우, 뒤 1.1초는 우→좌 베기로 나눈다. 짧게 누르면 앞 동작만, 계속 누르면 두 동작을 번갈아 반복한다. 동작 종료 뒤 다시 누르면 좌→우로 시작한다. 피해는 각각 원작 이벤트인 0.4초/0.233초에 기본 26, 명중 회복은 기존 규칙을 유지한다.
- E: 오른손을 왼어깨 위에 올린 후 치켜든다. 날개가 한번 튕긴 뒤 펼쳐지고 칼날은 X자로 벌어진다. 치마가 펄럭이고 3인칭 몸체는 최대 0.42m 부양한다. 1인칭은 오른손 동작만 보이며 카메라 높이는 유지한다. 0.667초에 기본 최대 HP 120의 40%인 **48 보호막**을 6초간 얻는다. 임시 최대 HP 증가로 보호막이 커지지 않는다. 은색 버블 표면을 사용하며 기존 소멸/파괴 폭발은 유지한다.
- Q: 4초 동작 중 캐릭터와 1인칭 시점이 최대 1.85m 상승했다가 돌아온다. 손에 소환한 창을 1.167초에 전방으로 보낸다. 전방 최대 12m 지점의 반경 4m 원형 구역에 3배 크기의 창이 내려온다. 2.067초에 착지하며 은색 수은 웅덩이를 5초간 남긴다.
- 창 직격 또는 착지 순간 원 안에 있던 적은 기본 **100 피해**를 한 번 받는다. 직격과 착지 피해는 중복하지 않는다. 나중에 들어온 적은 낙하 피해를 받지 않으며, 웅덩이 안에서 공격 약화와 도발이 유지된다. 벗어나거나 웅덩이가 사라지면 풀린다. 아군·벽 뒤·다른 층에는 적용하지 않는다. 피해량에는 게임의 팀/방어 배율이 적용된다.

서버와 예측 클라이언트, 관전자, 녹화 데스캠이 동일한 단계와 경과 시간을 사용한다. 네트워크 패킷 크기는 유지하지만 프로토콜 변경이 포함되어 같은 빌드끼리 접속해야 한다.

## 에셋과 재생성

창 시안은 `assets/effects/vivi-lance-concept.png`, 편집 모델은 `vivi-lance.blend`, 교환 모델은 `vivi-lance.glb`에 있다. 런타임은 같은 모델에서 내보낸 `vivi-lance-mesh.json`을 읽는다. 은색 날, 갈라진 가드, 버건디 홈과 긴 자루로 구성했다.

1. `node scripts/extract_vivi_skills.cjs`: 보관 Spine → `assets/characters/skill/vivi.json`.
2. Blender 백그라운드로 `scripts/bake_vivi_skills.py`: 기존 비비 메시/표정과 다른 동작을 보존하며 날개·치마 가중치 및 새 클립을 저장한다. 최초 백업은 `artifacts/vivi-skills/before/`에 보관한다.
3. Blender로 `scripts/model_vivi_lance.py`: 창의 Blender/GLB/런타임 메시를 만든다.

| 클립 | FBX 프레임 | 재생 길이 |
|---|---|---|
| Idle | 0–60 | 1.333초 |
| ViviLeft | 558–582 | 0.8초 |
| ViviRight | 585–618 | 1.1초 |
| ViviSkill | 621–665 | 1.467초 |
| ViviUltimate | 668–788 | 4초 |

## 실행 및 검증

`Play.cmd --solo --auto-start`로 연습장을 연다. `Play.cmd --vivi-skill-review --hud-review-small`은 3인칭/1인칭 28개 시점을 자동 캡처한다.

빌드: `cargo build --offline --no-default-features --features desktop --bin tsb-review`

전투 테스트: `cargo test --offline --no-default-features --test vivi_skill`. 네트워크 단계·타이머·최대 투사체 패킷 및 녹화 동작 테스트는 라이브러리 테스트에 포함된다. 원작 컨택트 시트·베이크 보존 검사·모델 렌더·GPU 로그는 `artifacts/vivi-skills/`에 기록한다.

검증 결과: 비비 전용 전투 8개, 기존 비비 전투 회귀 3개, 네트워크·데스캠을 포함한 라이브러리 208개 통과(공용 근접 자국 테스트 1개 제외). 실제 GPU 28장 검사에서 네 칼날, 좌우 베기, 오른손 및 왼손 숨김, 은색 보호막, 창/웅덩이 셰이더를 확인했다. `gpu-final.log`에 `VIVI_SKILL_REVIEW_OK`를 기록했다. 메시 좌표와 기존 비대기 클립의 키 보존도 검사했다.

전체 테스트 묶음은 현재 공유 작업의 클로에 근접 자국·기존 E/Q 기대값 및 유령 벽 내부 캐릭터 교환 검사에서 실패한다. 이 결과는 전체 통과로 간주하지 않으며 `tests.log`, `tests-all.log`, `tests-remainder.log`에 보관했다.

일반 실행판은 전체 15개 모델 로딩과 첫 화면 렌더를 확인했다. 공용 14초 smoke는 첫 메뉴 캡처 후 `SMOKE_FAILED`로 종료했으므로 통과로 기록하지 않았다(`play-smoke.log`). 비비 동작의 화면 검증은 시간 제한에 의존하지 않는 전용 28프레임 검사를 사용했다.
