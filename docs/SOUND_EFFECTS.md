# 효과음

2026-11-20 트릭컬 전투·UI 효과음 배포 자료를 재검색했지만, 바로 적용할 수 있는
전체 효과음 묶음은 확인하지 못했습니다. 검색되는 스피키 대사·밈 클립 대신
Kenney CC0 효과음 32개를 가져와 FPS 동작에 맞게 적용했습니다.
트릭컬 원본 효과음이나 캐릭터 성우 음성이 아닙니다.

## 출처

- [Interface Sounds](https://kenney.nl/assets/interface-sounds)
- [Impact Sounds](https://kenney.nl/assets/impact-sounds)
- [RPG Audio](https://kenney.nl/assets/rpg-audio)
- [Sci-fi Sounds](https://kenney.nl/assets/sci-fi-sounds)

원본 OGG, 팩별 라이선스, 파일명·출처·SHA-256 목록은 `assets/audio/sfx/`에 있습니다.
`scripts/import_sfx.py`는 `artifacts/sound-sources/`의 원본 ZIP에서 선택한 파일만
추출합니다. 런타임에는 음원을 EXE에 포함하여 별도 다운로드 없이 재생합니다.
포터블·단일 EXE 패키지에도 원본/라이선스 자료를 포함합니다.

## 적용

| 동작 | 소리 |
| --- | --- |
| 기본 공격 | 비비·아야 칼바람, 나이아 물, 에르핀·피코라·벨라 마법, 이드·리뉴아 레이저, 클로에·코미 타격, 마요·힐데 발사, 우이 맑은 음, 버터 새총, 시온 묵직한 발사 |
| E / Q | 실제 쿨다운 시작·궁극기 게이지 소비에 맞춘 발동음; 물·치유·기계·마법 계열 구분 |
| 전투 피드백 | 명중, 피격, 방벽 파괴 시 체력 피해, 벽 충돌, 재장전 시작/완료, 사망/부활, 궁극기 충전 완료 |
| 이동 | 실제 지면 이동 거리 기반 발걸음, 점프/착지, 종족 이동기, 포털 |
| 경기 / UI | 경기 시작, 거점 점령, 승패, 화면 전환, 캐릭터 선택/확정, 음량 조절 확인음 |

Esc → 설정 → 효과음 설정에서 0~100%로 조절합니다. 기본값은 65%, 0%는 음소거입니다.
마우스 감도와 함께 기존 사용자 설정 파일에 저장하며 팀 음성채팅 음량에는 영향을 주지 않습니다.

각 클립은 로딩 때 모노로 변환하고 피크를 통일하며 최대 2초로 제한하고 양 끝을 페이드합니다.
주변 소리는 카메라 기준 3D 방향·거리 감쇠를 적용합니다. 새 소리는 48m 밖에서 생성하지 않고,
동시 재생은 24개(주변 소리 18개)로 제한해 로컬 명중·재장전 소리가 묻히는 일을 줄입니다.
창 포커스를 잃거나 음소거하면 즉시 소리를 정리합니다.

서버 상태의 발사 카운터와 상태 변화로 재생을 결정합니다. 같은 네트워크 스냅샷,
늦은 입장, 맵·라운드 변경, 캐릭터 변경, 메뉴 복귀가 과거 효과음을 재생하지 않도록 처리합니다.
사망 리플레이에는 전투 효과음을 재생하지 않습니다.

## 확인 명령

```powershell
cargo test --lib --bin tsb --no-default-features --features desktop sfx::
cargo test --lib --no-default-features settings::
cargo run --bin tsb -- --solo --auto-start --sfx-review
cargo run --bin tsb -- --solo --auto-start --settings-review
```

`--sfx-review`는 38개 이벤트를 실제 Fyrox 장치로 재생하고, 재생 시간 진행·완료 소스 정리·
음소거를 검사한 다음 자동 종료합니다. 실제 마이크를 녹음하지 않습니다.

확인 결과: 라이브러리 테스트 205개, 음원 디코딩·재생 제한 테스트 2개 통과.
기본 기능의 `tsb.exe` 빌드 후 실제 장치 검사에서 38개 이벤트가 모두 재생·종료됐고,
960×640 설정 화면에서 음량 변경·0% 음소거·기본값 복원·저장을 확인했습니다.

실행 확인 중 버터 무기의 3개 변형 채널이 3개 재질 표면에 적용되면서 9개로 집계되어
로딩이 중단되던 기존 문제도 수정했습니다. 각 표면을 복원한 뒤 고유 채널 수를 검증하며,
기존 변형 매핑 테스트 2개와 실제 모델 로딩을 통과했습니다.
