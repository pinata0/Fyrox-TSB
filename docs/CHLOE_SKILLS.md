# 클로에 / 세바스티안 모션

`Play.cmd --solo --auto-start --chloe-practice --lan`으로 클로에를 선택한 연습 모드를 실행한다. `Review.cmd --solo --chloe-skill-review --lan`으로 1·3인칭 39개 장면을 캡처하고 종료한다. 일반 플레이는 `tsb`, 화면 검증은 공통 `tsb-review`를 최신 소스에서 빌드한다.

## 동작

- 일반 폼: 1인칭에는 세바스티안의 분홍/민트 손만 표시한다. `Move`를 참고한 달리기에서는 클로에가 볼을 받치고, 세바스티안은 감은 눈과 처진 팔다리로 뒤따른다.
- 기본 공격: 0.23초에 적중하는 총 0.8초 공격. 일반 27 / 탑승 40 기본 피해. 1인칭 세바스티안 팔은 화면 양쪽 아래 모서리에서 올라오며, 오른팔이 바깥으로 준비한 뒤 안쪽 위로 크게 휘두른다. 이동 공격은 공격하는 세바스티안 팔만 덮어씌우며 다른 팔·다리는 이동 모션을 유지한다.
- E: `Skill1_1` 기반 2초 탑승 전환. 팔 벌리기와 가위눈을 포함한다. 탑승 완료부터 12초를 세며 잔여 시간 막대와 적중 수를 표시한다.
- 탑승 idle/move: `Idle_SebastianForm`, `Move_SebastianForm` 기반. 1인칭은 세바스티안 팔을 비탑승의 1.38배로 키우고 클로에 손도 함께 표시한다. 클로에 양손은 대기·이동·공격 내내 같은 위치와 방향을 유지하며, 공격은 세바스티안 팔만 휘두른다. 3인칭 손가락질·이동 표정·팔꿈치를 올린 세바스티안 보행을 유지한다. 카메라는 1.65m 올라간다.
- 탑승 중 9회 적중: 한 번의 휘두르기로 여러 명을 맞혀도 1회로 센다. 12초로 갱신하고 `Skill1_1_SebastianForm` 기반 포효. 0.63초에 반경 6m의 보이는 적 모두에게 기본 45 피해. 총 2초 동안 이동할 수 없으며 1인칭은 양손으로 귀를 막는다. 포효 중에도 지속시간은 흐른다.
- 종료: `Skill2_1` 기반 2초 강제 하차. 짧게 뛰어내린 뒤 일반 폼과 낮은 시점으로 복귀한다.
- Q: 등 뒤 3×3 배치에서 작은 세바스티안 9마리 출발. 16m 안의 보이는 적을 추적하고, 5초가 지나거나 벽에 닿으면 사라진다. 적 접촉 시 반경 2m 기본 14 피해·넉백·0.7초 색종이 효과. 별도 캐릭터 시전 모션은 없다.
- 기본 원거리 피격의 치명타 위치는 탑승한 클로에의 머리다. 앞·옆·뒤 방향과 뒤로 옮겨진 머리 위치를 반영하며 세바스티안 머리는 치명타가 아니다. 치명타 배율 1.5. 기본 피해에는 기존 팀 조합·보호막·상태 효과 규칙을 적용한다.

지속시간 등 수치가 지정되지 않은 부분은 위 값을 초기값으로 사용했다. 사망, 캐릭터 교체, 변이 시 탑승 상태를 초기화한다. 적중·피해·타이머는 서버 권위로 처리하고 기존 스냅숏 크기를 유지한다.

## 팔 길이 보정

2026-11-20: 긴 팔은 세바스티안의 볼을 받치는 동안에만 쓴다. 탑승·포효·탑승 전환의 받치기 해제, 볼 당김 반응, 손 인사에서는 해당 팔을 원본 Meshy 모델의 길이(위팔 약 0.153m, 아래팔 0.164~0.169m)로 즉시 복원한 뒤 회전과 IK를 적용한다. 소매는 길이 축만 줄인 독립 표면으로 바꾸므로 두께와 손 크기가 유지된다. 다시 볼을 받칠 때는 원래 받치기 애니메이션과 긴 소매를 사용한다. 아래 0.50/0.40m 검증값은 받치기용 원본 FBX의 길이다. 실행 중 전환은 `chloe_arms.rs`와 `--cheek-review`, `--chloe-skill-review`에서 추가로 검사한다.

1인칭 클로에 손은 무기를 잡는 좌우 반전 소켓 대신 실제 중지·검지·새끼손가락 축으로 방향을 잡는다. 엄지가 안쪽을 향하고 손가락이 소매 앞으로 나오는 가벼운 굽힘 자세다. 손·소매는 공통 1인칭 크기의 72%로 조정하여 바깥의 세바스티안 팔과 구분한다. E 팔 벌리기와 포효 중 귀 막기는 유지하되, 이동 손가락질과 공격 밀치기를 클로에의 1인칭 손에서 제거했다. 세바스티안 팔 크기는 탑승·하차 카메라 전환에 맞춰 부드럽게 변한다. 추출 메시의 길이 축은 1.6배로 고정하여 큰 공격에도 잘린 어깨 끝이 화면 밖에 남게 한다. 공격 진행에 따른 팔 길이 변화는 없다.

손 목표가 멀 때 팔을 늘리지 않고 도달 범위를 제한한다. 위팔·아래팔의 위치와 배율은 기준 자세 값으로 고정하고 회전만 푼다. 소매는 각 구간에 고정된 두 메시와 둥근 팔꿈치 연결부로 구성하여 굽힐 때 긴 면이 늘어나지 않게 했다.

`scripts/verify_chloe_skills.py`는 730개 자세(프레임 사이 포함)를 검사한다. 기준 길이는 오른팔 약 0.520/0.412m, 왼팔 0.502/0.397m이며 최대 길이 오차는 약 0.00132m이다. GPU 검수에서도 양팔 길이와 1인칭 손 교체를 확인한다.

## 원본과 재생성

원본 2D 모션 데이터는 `assets/characters/skill/chloe.json`, 3D 모션은 `assets/characters/chloe.blend`/`chloe.fbx`에 있다. 런타임은 2D 스프라이트가 아닌 3D 모델을 재생한다.

| 모션 | 30fps 프레임 |
| --- | --- |
| ChloeAttack | 531–555 |
| ChloeMount | 558–618 |
| ChloeRideIdle | 621–661 |
| ChloeRideMove | 664–684 |
| ChloeRideAttack | 687–711 |
| ChloeRoar | 714–774 |

재생성: Blender에서 `scripts/bake_chloe_skills.py`, `scripts/build_chloe_view_hands.py`, `scripts/verify_chloe_skills.py` 순서로 실행한다. 기본 bake는 `artifacts/chloe-skills/before`의 최초 백업을 사용하며 무관한 기존 애니메이션 키를 검증한다.

포효 효과음은 원작 음성이 아닌 trazzz123의 [CC0 Deep Monster Roar](https://opengameart.org/content/cc0-deep-monster-roar)를 사용한다. 1.5초 발췌 및 페이드 처리했고, 출처와 가공 내역은 `assets/audio/sfx/LICENSE-sebastian-roar.txt`에 기록했다.

## 검증

- 클로에 전용 테스트 14개와 네트워크 테스트 2개 통과. 손 고정·큰 휘두르기·전환 경계 회귀 검사를 포함한다. 기존 이동 공격 검사는 고정 거리 대신 현재 `WALK_SPEED * DT`를 기준으로 삼는다.
- 화면 캡처: `artifacts/preview-chloe-skills-*.png`.
- 이번 1인칭 수정은 `tsb-review.exe` 빌드와 39개 GPU 검수 장면을 통과했다. 최종 캡처·실행 로그·해시는 `artifacts/chloe-first-person/`에 보관한다. 검수는 손바닥 위치·손가락 전방 방향·소매 방향·세바스티안 팔 크기·어깨 끝의 화면 밖 배치를 확인한다. `Play.cmd --solo --auto-start --chloe-practice --lan`로 수정 빌드를 실행한다.
- 전체 headless 테스트에서는 별도 기능의 기존 기대값과 충돌하는 실패 4개가 남아 있다: 유령 교체 제한 1개, 코미 Q 충격파 2개, 비비 즉시 2타를 가정한 정령 보호막 1개. 클로에 변경으로 이 기대값을 수정하지 않았다.
- 공통 `--smoke-test`는 14초 안에 요구하는 모든 캡처·Q·댄스 단계를 완료하지 못했다. 클로에 전용 GPU 검수는 최종 모델로 21개 장면을 모두 통과했다.
- 일반 EOS 포함 `tsb.exe`와 연습/검수용 `tsb-review.exe` 빌드를 모두 완료했다.

빌드: `cargo build --no-default-features --features desktop --bin tsb-review`
