# 6 대 6 초기 로스터 제안

기록일: 2026-11-12. 사용자가 아래 **15명 로스터를 승인**했고, 현재 실행 코드에 **6 대 6, 캐릭터 선택, 팀 시너지, 7종족 패시브, 포지션 상한**을 구현했다. 16/20/30명 규모는 향후 확장 비교안으로 남긴다. 캐릭터는 개별 Blender MVP 모델·11종 모션·선택창 초상화를 사용하며, 15명 각자의 기본공격·E·Q를 원작 기반으로 각색했다. 스폰 H 교체와 궁극기 최대 15% 보존은 [선택 사양](HERO_SELECTION.md)에 기록한다. [키트 조사와 구현 수치](CHARACTER_KITS.md)에 상세 내용을 기록한다.

## 사용자 확정 규칙

- 목표 경기 인원: **6 대 6**, 경쟁전식 2CP.
- 성격: 순수, 냉정, 광기, 활발, 우울.
- 같은 팀의 같은 성격 캐릭터 두 명마다 **팀 전체 공격력 +20%**.
- 종족: 요정, 수인, 엘프, 정령, 유령, 용족, 마녀. 종족마다 다른 패시브.
- 포지션: 전열, 중열, 후열. 한 팀에서 같은 포지션은 최대 3명.

## 계산 가정과 시너지

MVP는 같은 팀의 동일 캐릭터 중복 선택 금지, 상대 팀과 동일 캐릭터 선택 허용, 밴 없음으로 구현한다. 성격 보너스는 기본 공격력에 가산한다.

`팀 공격력 배율 = 1 + 0.2 × Σ floor(각 성격의 팀 인원 / 2)`

- 6, 4+2, 2+2+2: 모두 +60%.
- 3+3, 3+2+1, 4+1+1, 2+2+1+1: 모두 +40%.
- 보너스는 성격별로 계산한 뒤 합산하며, 각 캐릭터가 중복해서 제공하는 오라로 처리하지 않는다.
- 구현: 살아 있는 인원 대신 현재 선택된 팀 로스터로 계산한다. 사망마다 전원의 공격력이 변하지 않는다.

## 권장 규모

| 인원 | 의미 |
| --- | --- |
| 10명 | 다섯 성격 모두에 최소 한 쌍을 제공하는 하한. 성격별 2명으로 짝이 고정되어 교체 선택지가 부족하다. |
| **15명** | **권장 최소. 각 성격에 전열·중열·후열 1명씩 제공한다.** |
| 16명 | 15명 기반에 스피키를 추가해 인지도와 순수 후열 선택지를 보강하는 선택안. |
| 20명 | 성격별 4명. 다섯 성격 모두가 4+2 조합의 중심이 될 수 있다. |
| 30명 | 성격별 6명. 다섯 성격 모두 단일 성격 6인 조합을 지원한다. MVP에는 불필요하다. |

15명은 주어진 규칙에서 강제되는 수학적 최솟값이 아니라, 성격마다 세 포지션의 선택지를 보장하기 위한 설계 기준이다. 7종족을 모두 넣기 위해 모든 성격·종족·포지션의 교차 조합을 만들 필요는 없다.

성격별 세 포지션을 한 명씩 둔 15명에서 최대 시너지는 2+2+2로 얻는다. 성격 세 개를 고르는 10가지와 각 성격에서 두 명을 고르는 3가지씩을 곱하면 `10 × 3³ = 270`개다. 이 구성은 같은 포지션이 최대 세 명이므로 모두 포지션 제한을 만족한다. 이 중 전열·중열·후열이 정확히 2명씩인 조합은 `10 × 3! = 60`개다.

15명 중 6명 선택을 전수 열거해 포지션 제한을 만족하는 조합 4,300개, 그중 최대 시너지 270개, 최대 시너지이면서 2/2/2인 조합 60개를 확인했다. 이는 편성 가능성 검증이며 실전 밸런스나 모든 조합의 경쟁력을 보장하지 않는다.

## 캐릭터 후보

기본 버전의 성격·종족·포지션을 사용한다. 원작 포지션과 FPS의 탱커·딜러·힐러 역할은 별도이며, FPS 스킬 설계에서 치유와 방어 수단을 확보해야 한다.

| 성격 | 전열 | 중열 | 후열 |
| --- | --- | --- | --- |
| 순수 | 비비 — 용족 | 나이아 — 정령 | 에르핀 — 요정 |
| 냉정 | 이드 — 엘프 | 아야 — 마녀 | 피코라 — 마녀 |
| 광기 | 클로에 — 요정 | 리뉴아 — 엘프 | 마요 — 요정 |
| 활발 | 벨라 — 유령 | 우이 — 정령 | 버터 — 수인 |
| 우울 | 코미 — 수인 | 힐데 — 엘프 | 시온 더 다크불릿 — 유령 |

캐릭터 속성 확인: [트릭컬 캐릭터 데이터베이스](https://gagether.wiki/ko/games/trickcal/characters?region=kr).

인지도는 [2026년 3월 커뮤니티 인기 투표 분석](https://froghome-island.tistory.com/10)을 참고했다. 공식 전체 이용자 조사와 다르며, 팬덤 선호의 참고 자료로만 사용한다. 버터·시온·에르핀·마요 등 인기 후보를 포함하면서 7종족과 성격별 세 포지션을 채운다. 나이아·피코라·우이·힐데는 FPS에서도 회복/지원 역할을 맡기는 안이다. 스피키는 16번째 추가 후보(순수·후열·유령)다.

최대 시너지와 2/2/2 배치를 만족하는 예시:

- 유지력 구성: 전열 비비·코미 / 중열 나이아·우이 / 후열 버터·시온. 순수 2 + 활발 2 + 우울 2. 나이아·우이를 회복 담당으로 설계한다.
- 사격전 구성: 전열 이드·클로에 / 중열 리뉴아·힐데 / 후열 피코라·시온. 냉정 2 + 광기 2 + 우울 2. 힐데·피코라를 회복 담당으로 설계한다.

## 구현한 종족 패시브

2026-11-13: 유령의 피격 가속을 벽 통과로 교체했다. 벨라와 시온에게 적용하며, 서버의 벽 접촉 상태로 모든 클라이언트가 같은 면에 물결을 표시한다. 파문은 접촉 종료 후 약 0.85초에 소멸하며, 벽 안에서 정지·후퇴가 가능하다. 공격과 투사체는 기존 벽 충돌을 유지하고, 벽 안에서는 다른 캐릭터로 교체할 수 없다.

팬게임용 신규 효과. 모두 **자기 자신에게만** 적용하며, 같은 종족의 팀원이 있다고 중첩되는 팀 버프는 아니다. 자동 테스트로 동작을 검증했으며 수치는 밸런스 플레이테스트 전 초기값이다.

| 종족 | 패시브 |
| --- | --- |
| 요정 | 받는 치유량 +10%. |
| 수인 | Shift 도약: 바라보는 방향으로 포물선 도약. 시선 높이에 따라 거리·높이 조절, 공중에서 약한 방향 조절. 발동부터 6초 쿨타임. 착지 시 추진 종료, 벽·천장 충돌 유지. |
| 엘프 | 재장전 시간 -10%. |
| 정령 | Shift 잠복: 지상에서 발동, 최대 4초간 무적으로 이동. 좌클릭을 0.6초 연속 누르면 일찍 솟아오르며, 시간 만료·낭떠러지 이탈 시에도 자동 종료. 종료부터 8초 쿨타임. 잠복 중 공격·E/Q·점프·거점 점유 불가, 벽 통과 불가. |
| 유령 | 패시브 벽 통과 제거. 전용 공용 스킬 Shift 영체화: 3초 지속, 종료 후 12초 쿨타임. 만료 시 벽 밖으로 배출. 조준점 주변 지속시간 링과 오른쪽 하단 스킬 슬롯 표시. 바닥·천장·맵 외곽은 통과 불가. |
| 용족 | Shift 몸통박치기: 3초간 기본 속도의 5배(17.4m/s)로 강제 전진. 시선·좌우 입력으로 방향 조절, 후진 입력으로 정지 불가. 충돌한 적마다 발동당 기본 30 피해 1회. 종료 후 8초 쿨타임. 기절·수면·포탈 이동·캐릭터 변경 시 종료. 벽·바닥 충돌과 밀쳐내기 거리 -30% 유지. |
| 마녀 | 일반 스킬 재사용 대기시간 -5%. 궁극기 제외. |

대부분의 최적화된 팀이 공격력 +60%를 확보할 수 있으므로 무기 피해량과 체력은 해당 배율을 기준으로 조정한다. 포지션 제한만으로 탱커/힐러 수가 보장되지는 않으므로, 캐릭터 스킬과 공격/수비 플레이테스트로 조합의 실제 성능을 검증한다.
