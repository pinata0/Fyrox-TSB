# 요정·마녀 공용 Shift — 쾌속 전진

에르핀·클로에·마요(요정), 아야·피코라(마녀)가 Shift를 새로 누르면 발동한다. 시작 시 바라보는 수평 방향으로 25m/s, 0.15초(60Hz 9틱), 총 3.75m를 이동한다. WASD·시선 변경으로 이미 시작한 전진 방향을 바꾸지 않는다. 공중에서도 사용할 수 있고 중력·벽·천장·계단 충돌을 유지한다. 벽에 막히면 남은 전진을 취소한다.

초기 3회, 최대 3회 충전. 사용 즉시 1회를 소모하고 3초마다 1회씩 순차 회복한다. 남은 충전을 추가 사용해도 진행 중인 충전 시간을 초기화하지 않는다. Shift 유지로 자동 재발동하지 않는다. 캐릭터·종족 교체 시 충전 횟수와 진행 시간을 유지하고, 리스폰·새 라운드에서는 3회로 복구한다. 기존 다른 종족 스킬 쿨타임도 교체로 우회하지 않는다.

기본공격 모션 중에도 발동하며, 전진 중에도 기본공격을 이어갈 수 있다. 클로에의 일반·탑승 기본공격도 공격 타이밍과 적중 판정을 유지한다.

순간이동이나 무적이 아니다. 일반 피해를 그대로 받으며 기절·수면·스킬 채널링 상태에서는 발동할 수 없다. 이동 중 해당 상태가 되면 전진을 취소하고, 상태가 풀려도 남은 전진을 재개하지 않는다. 클로에의 탑승·포효·하차 모션은 기존처럼 전진을 제한한다.

## 장판 접촉

기존 코드에는 지속 장판용 접촉 객체가 없어 `World::ground_effects`와 `GroundEffect`를 추가했다. 맵이나 스킬은 소유자·범위·피해·기절 시간·지속시간·대상별 적중 간격을 등록할 수 있다. 이번 변경에서 기존 캐릭터의 E/Q를 새 장판 스킬로 바꾸거나 맵에 임의의 함정을 배치하지는 않았다.

일반 보행과 쾌속 전진이 같은 실제 이동 경로를 사용한다. 벽 충돌·계단을 반영한 각 경로 구간과 장판 체적을 연속 교차 판정하므로 얇은 장판도 건너뛰지 않는다. 경로 순서대로 기존 서버 피해 계산을 적용하고, 기절·사망 시 접촉점에서 경로를 잘라 뒤쪽 장판이나 몸통 충돌을 처리하지 않는다. 여러 이동 세부 단계가 같은 장판에 닿아도 대상별 피해 간격을 유지한다. 아군·리스폰 보호·잠복 무적과 기존 피해 출처·처치 계산을 따른다. 발 위치가 범위 위에 있으면 지면 장판을 뛰어넘을 수 있다.

장판 피해·기절은 서버 판정이다. 클라이언트는 이동과 충전을 예측하고 서버가 기절을 확정하면 위치 보정 잔차를 즉시 제거한다. 장판 자체의 그래픽·배치·네트워크 시각 효과는 장판을 생성하는 개별 스킬에서 연결할 부분이다.

## 표시·통신·검증

Shift HUD는 전진 화살표, `3/3` 형태의 남은 횟수, 다음 1회 충전까지 남은 초와 진행 바를 표시한다. 프로토콜 TSBO는 모든 종족의 충전 횟수·시간을 저장하고 로컬 전진 방향도 동기화한다. 이벤트 문자열 예산을 24바이트 줄여 1200바이트 미만 패킷을 유지한다.

- `tests/surge.rs`: 5명 이동, 3회 소모와 충전, 입력 유지, 상태이상 중단, 얇은 기절 장판, 피해 간격·사망, 벽·공중 이동, 일반 보행, 교체·리스폰.
- `src/prediction/tests.rs`: 서버와 예측 이동·충전 일치, 기절 시 위치 보정.
- `src/net/race_skill_tests.rs`: 모든 종족의 충전 직렬화, 잘못된 상태 거부, 실제 UDP의 소유자·관찰자·후발 접속·재충전.
- `--race-skill-review --auto-start`: 요정 준비, 마녀 2회, 요정 1회, 소진, 장판 기절 HUD 장면을 기존 검증에 추가. `--hud-review-small`로 작은 화면도 확인한다.
