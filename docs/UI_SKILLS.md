# 우이 스킬

원본은 `assets/references/ui-motion-reference.skel`의 Normal 스킨이다. `scripts/extract_ui_skills.cjs`가 Spine IK와 회전·크기 곡선을 30fps로 평가한다. 결과는 `assets/characters/skill/ui.json`에 보관한다.

## 기본공격 — 지팡이 발광·발사

- 공격 순간 클로버 중심에 연두색 빛이 퍼지고 0.24초 동안 사라진다. 툰 렌더러에서 블룸을 꺼도 표시된다.
- 1인칭과 외부 시점 모두 애니메이션이 적용된 클로버 중심에서 마력탄이 출발한다. 발사 위치는 한 번만 저장하고 0.1초에 걸쳐 기존 조준 궤적으로 연결하므로, 발사 후 지팡이를 움직여도 탄이 끌려가지 않는다.
- 네 번째 기본공격의 즉시 적중 광선도 같은 클로버 중심에서 시작한다. 피해량·탄속·명중 판정은 기존 전투 규칙을 유지한다.
- 우이에게 쓰이지 않던 마력탄 수 비트로 기본공격 순서를 전달하여 참가자·관전자도 네 번째 공격을 구분한다. 패킷 크기는 늘어나지 않는다.
- `Review.cmd --solo --lan --ui-attack-review`는 대기·발사·비행·복귀·네 번째 공격·외부 시점의 6장을 캡처하고, 클로버와 발사점의 일치 및 발광 종료를 검사한다.

## 저학년 E — 개굴비

- `Skill1_1`: 65프레임, 2.167초. FBX 구간 531–596.
- 원본 효과 이벤트인 22프레임(0.733초)에 시전자 발밑을 중심으로 고정된 반경 7m 비 영역을 만든다. 영역은 시전자가 이동해도 따라가지 않는다.
- 비는 4초간 유지되며 0.5초마다 총 8회 작동한다. 아군은 기본 HP 4 회복, 적은 기본 피해 3. 기존 팀 공격 보너스·회복 보정·보호막 규칙을 적용한다.
- 영역 안의 적은 이동속도가 15% 감소한다. 기존 35% 감속과 중첩 시 강한 감속을 적용한다. 나가면 다음 시뮬레이션 틱에 해제된다.
- 벽에 가려지거나 높이 차이가 2.5m를 넘는 대상은 제외한다. 시전자도 영역 안에 있으면 치유받는다. E 쿨타임 감소 효과는 없다. 쿨타임은 12초.
- 양손은 같은 줄기의 두 지점을 잡는다. 네잎클로버는 줄기와 별도 메시·허브로 분리되어 원본의 두 바퀴 이상 회전과 잎의 늘어남을 재현한다. 기존 줄기의 녹색 텍스처를 사용하는 가는 고정 축으로 잎의 회전 중에도 줄기가 연결된다. 기존 Hair 본에는 묶은 머리 뿌리와 끝의 원본 움직임을 함께 적용한다.

## 고학년 Q — 말하는대로!

- `Ultimate1_1`: 127프레임, 4.233초. FBX 구간 599–726.
- 우이의 Hips와 에루의 Mount를 각각 구동한다. 원본의 세 번 도약·착지 궤적을 따라 우이가 에루 위로 분리되어 튀고 복귀한다.
- 클로버 회전 및 크기 곡선은 원본 `Weapon_Leaf_0`와 `Weapon_Leaf_1`에서 추출한다. 잎 크기는 약 0.738–1.875배 범위에서 맥동한다.
- 첫 도약 효과 이벤트인 29프레임(0.967초)에 현재 시야의 대상을 한 번 수집한다. 수직 80°와 실제 화면 비율, 상하 조준, 머리/몸통의 가림을 판정한다. 임의 거리 제한은 없다. 뒤쪽, 벽 뒤, 사망·비활성·잠복 대상은 제외한다.
- 먼저 보이는 모든 적을 3초간 개구리로 변이시킨다. 이어 보이는 모든 아군의 E 쿨타임을 0으로 만든다. 자신은 시야 대상에 포함하지 않는다. 고학년·종족 스킬·재장전은 초기화하지 않는다.
- 변이는 걷기와 시점 회전을 허용한다. 기본/보조 공격, E/Q, 종족 스킬, 점프, 앉기, 재장전, 춤/인사, 조준 확대는 불가능하다. 이미 시작한 행동도 취소한다. 무적·디버프 면역과 스폰 보호는 존중한다.
- 원래 캐릭터와 장비 대신 에루의 기존 개구리 메시를 표시한다. 이동 충돌 캡슐과 피격 판정 크기는 기존 캐릭터 규칙을 유지한다. 사망·정화·만료 시 원래 모습으로 복구한다.

## 동기화와 검증

전투 효과는 서버에서만 적용한다. 저학년/고학년 시전 시계, 비 영역 위치·나이, 변이 남은 시간, 15% 감속을 네트워크로 전송한다. 캐릭터 스냅샷은 기존 1200바이트 한도와 크기를 유지한다. 시야 비율은 입력 패킷에 추가되므로 호스트와 클라이언트를 함께 업데이트해야 한다.

`scripts/bake_ui_skills.py`는 기존 0–528프레임 키와 모든 메시 좌표가 유지되는지 검증하고 원본 백업을 `artifacts/ui-skills/before`에 남긴다. 무기 분리는 `scripts/split_ui_clover.py`로 재현한다.

```powershell
cargo test --no-default-features --test ui_skill
cargo test --no-default-features --lib ui_tests
cargo run --no-default-features --features desktop --bin tsb-review -- --ui-skill-review
```

1인칭에서는 평소와 고학년 사용 중에는 오른손으로 클로버 지팡이를 잡고, 저학년 시전 중에만 왼손을 더해 양손으로 잡는다. 시전이 끝나면 즉시 한 손 자세로 돌아온다.

화면 검증은 저학년 회전·비, 고학년 세 번 도약·잎 크기 변화·개구리, 1인칭 한 손/양손 전환과 시전 후 복귀를 15장으로 캡처한다.

2026-11-20 검증: 우이 전투 7개, 우이 네트워크 3개 통과. 루프백 통신이 가능한 환경에서 전체 387개 통과, 기존 고스트 캐릭터 교체 1개 및 코미 충격파 가정의 로스터 2개가 실패했다. 이 3개는 우이 스킬 경로를 사용하지 않는 별도 작업 영역이다.

최종 화면 검증에서 외부 시점의 양손 손바닥과 손잡이 소켓의 간격은 5mm 미만, 1인칭에서 표시되는 손의 접점 오차는 1mm 미만임을 검사한다. `Play.cmd`로 수정본을 실행할 수 있다.
