# 생성 모델의 손 리깅·무기 파지 보정

후속 [손·소매 메시 정리](HAND_MESH_POLISH.md)에서 아래에 기록된 소매·메시 경계 한계를 추가로 수정했다. 이 문서는 이전 HandGrip 판의 변경 기록이다.

이전 Meshy 적용판은 손가락 가중치를 `Hand.L/R`에 합쳤고, 손가락이 없는 경우 검증을 생략했다. 무기와 손목의 위치가 같다는 검사만 통과했으므로 실제로 손잡이를 쥐는지 보장하지 못했다.

## 변경

- 15명의 양손에 손가락별 3관절(총 450개)을 추가하고, 실제 손 표면의 정점 가중치를 연결했다. 원본이 손가락이 붙어 있는 장갑 형태인 경우 기존 메시를 구부려 쥐게 한다. 원본에 없는 손가락 틈이나 손톱을 새로 모델링하지는 않았다.
- 손목이 소매 위에 잡혀 있던 모델은 보이는 손의 시작 위치로 관절을 옮겼다. 소매 가중치는 아래팔로 넘겨 손가락을 굽힐 때 옷이 말려 들어가지 않도록 했다. 손바닥 안쪽에는 별도 `PalmGrip.L/R` 기준점을 배치했다.
- 손가락 사이 가중치는 부드럽게 섞고 피부 색 경계 주변의 연결된 표면까지 포함한다. 1인칭 팔은 손가락과 연결된 메시 성분을 골라, 자동 가중치가 잘못 붙은 별도 머리카락을 제외한다. UV 경계의 중복 정점은 위치로 연결 관계를 판단한다.
- 1인칭과 외부 시점 모두 손바닥 위치와 손잡이 축을 맞춘다. 양손 무기는 반대손의 방향과 두 팔의 도달 범위를 계산한다. 새총의 움직이는 고무줄 접점도 변환 갱신 후 읽는다.
- 무기를 들면 쥐고, 인사·선택·춤에서는 손을 편다. 마법을 띄우는 리뉴아·벨라는 가볍게 굽힌 손을 사용한다. 1인칭은 아래팔·소매를 손바닥 방향으로 함께 돌려 손목에 접힘이 집중되지 않게 하고, 외부 시점은 아래팔에도 비틀림을 나누어 준다.
- 180도에 가까운 회전에서 엔진의 반복 행렬 분해가 불안정해지는 경우를 피하도록, 본 회전은 정규 직교 행렬에서 직접 쿼터니언으로 변환한다. 애니메이션 직후에는 위치와 회전이 같은 프레임의 값을 사용하도록 계층 변환을 먼저 갱신한다.

본체 정점·UV·23개 얼굴 모프는 유지한다. 공통 11모션은 같은 타이밍을 사용하고, 기존 볼 당김 상한도 유지한다.

원본의 큰 소매와 거친 메시 경계는 일부 1인칭 실루엣에 남아 있다. 이번 수정은 손가락 변형·손바닥 접점·팔 자세를 바로잡는 범위이며, 손가락 사이를 새로 뚫거나 소매의 잘린 면을 재모델링한 것은 아니다.

## 파일과 검증

편집 모델·게임 FBX는 `assets/characters/`에 있고 손 관절·굽힘 축·파지 위치는 `<캐릭터>-hands.json`에 있다. `.L`은 좌표가 음수인 해부학적 오른손이다. 교체 전 모델은 `artifacts/meshy-hand-fix/before/`에 보관했다.

`scripts/rig_meshy_hands.py`는 보존된 수정 전 모델에서 손 리그를 다시 만든다. 이미 수정된 모델에 관절을 중복 추가하지 않는다. 후속 모델 편집을 재생성할 때는 이 스크립트가 읽는 기준 모델도 함께 갱신해야 한다.

`scripts/verify_meshy_hands.py`는 각 손가락의 실제 가중치와 열린/닫힌 메시 변위, 손바닥과 손목의 분리, 유한값과 얼굴 모프 보존을 검사한다. `scripts/verify_meshy_assets.py`는 전체 모션·루프와 독립 FBX 재가져오기를 검사한다.

게임의 `--weapon-review --auto-start --hud-review-small` 검사는 15명 대기·공격·재장전, 양검 공격, 인사와 복귀, 외부 시점 파지를 확인한다. `--support-grips-only`를 더하면 아야·버터·코미·시온의 1인칭 및 외부 시점 대기/공격 16장만 검사한다. 이제 손가락 관절이 없거나 닫히지 않으면 실패하고 손바닥 접점 및 손잡이 축도 확인한다. 양손 파지 중 팔이 몸의 중앙선을 넘는 것은 정상 동작이므로 본 이름과 양의 행렬식을 통해 좌우를 검증한다.

최종 검증 결과와 실행 파일 해시는 `artifacts/meshy-hand-fix/validation-report.json`에 기록한다.

실행 파일은 `release/TSB-Multiplayer-HandGrip.exe`이다. 이전 `TSB-Multiplayer-Meshy.exe`에는 이 수정이 들어 있지 않다.
