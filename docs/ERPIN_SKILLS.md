# 에르핀 저학년·고학년 모션

`Play.cmd`는 최신 소스의 `tsb`를 일반 플레이 모드로 실행한다. 화면 검증은 공통 `tsb-review`를 사용한다.
빌드: `cargo build --bin tsb-review`.

## 저학년 E

- 보관된 Spine `Skill1_1`의 85프레임을 30fps로 재생한다.
- 1인칭은 지팡이를 세운 채 눈높이 위로 높이 들고, 첫 마력탄이 나오는 51프레임에 맞춰 앞으로 내려친다. 마지막 발사 후 자연스럽게 기본 자세로 돌아오며, 준비 중 지팡이를 뒤로 젖히지 않는다.
- 1인칭 왼손은 두 마디를 접어 주먹을 쥐고, 손바닥 쪽을 위쪽·플레이어 쪽으로 기울여 저학년 시전 중 손등이 정면에 보이지 않도록 한다.
- 원본 발사 이벤트인 51·54·59·64프레임에 지팡이의 분홍색 보석 중심에서 마력탄을 한 발씩 발사한다. 1인칭·외부 시점 모두 기본 공격과 같은 보석 기준점을 사용한다.
- 마력탄은 전방으로 20m/s 비행하고 적·벽·바닥에 착탄하면 보라색으로 폭발한다. 각각 피해 14, 반경 2m이며 엄폐와 아군 피해 규칙을 따른다.
- 25프레임 부근부터 눈을 크게 뜨고 눈썹을 비대칭으로 올리며 입을 벌리고 입꼬리를 내린다. 원본의 당황 구간에 식은땀도 표시한다.
- 캐스팅 중 다른 스킬·공격은 제한된다. 사망·강한 행동 불가 상태는 남은 발사를 취소한다.

## 고학년 Q

1. `Ultimate1_1` 준비 동작 35프레임.
   - 준비 중 바닥 범위 표시는 가운데가 빈 주황색 링으로 표시한다.
2. `Ultimate1_2_Loop` 16프레임을 반복하면서 최초 방향으로 18m/s 직진한다. 시간제한이 없으며 WASD·시점 회전·점프·다른 행동으로 멈추거나 방향을 바꿀 수 없다. 감속·시간 감속·강제 정지·밀쳐내기에 방해받지 않으며 사망하면 종료된다.
3. 지형이나 캐릭터와 처음 충돌하면 노란 폭발로 주변 적에게 피해 70(반경 2.2m)을 한 번 적용한다. 아군과 부딪혀도 아군에게 피해를 주지는 않는다.
4. 에르핀 자신이 위로 튀면서 뒤로 약 5.7m 날아간다. 반동도 벽을 관통하지 않는다.
5. `Ultimate1_3` 90프레임 동안 기절하며 공격·이동·다른 스킬을 사용할 수 없다. 머리 위 노란 표시와 기존 기절 HUD를 사용한다. 시간 정지로 회복 동작이 멈추면 기절도 동작 종료까지 유지한다.

## 리소스와 재현

- 추출: `node scripts/extract_erpin_skills.cjs`
- 베이크: `blender --background --python scripts/bake_erpin_skills.py`
- 원본: `assets/references/erpin-motion-reference.skel`
- 런타임 샘플: `assets/characters/skill/erpin.json`
- FBX 타임라인: E 584–669, Q 준비 672–707, Q 반복 710–726, Q 회복 729–819.
- 기존 0–581프레임, 얼굴 모프, 케이크, 손과 독립 날개를 보존한다.
- 머리 뒤 위쪽 회색 금속 잔여물의 정점 291개를 제거하고 Head에 연결된 머리카락 패치로 열린 부분을 메웠다. 왕관과 양쪽 날개는 보존했다.
- 상태·경과 시간·폭발 연출은 기존 크기의 네트워크 패킷에 실린다. 서버와 클라이언트가 돌진 충돌·반동 코드를 공유하며 피해는 서버만 적용한다.

## 검증

- `tests/erpin.rs`: 기존 공격·케이크 테스트 7개 통과.
- `tests/erpin_skill.rs`: 발사 타이밍·범위 피해·무제한 돌진·감속 무시·벽과 신체 충돌·반동·기절·중단·예측·시간 정지 테스트 8개 통과.

- GPU 검증: `target/debug/tsb-review.exe --attack-review --erpin-only --erpin-skills-only`.
- 실제 게임의 월드·1인칭 12장 캡처와 손–지팡이 접점 검사 통과. `artifacts/preview-erpin-40-ErpinSkill-game.png`부터 51번까지.
- 베이크 보존 검사: `artifacts/erpin-skills/bake-verification.json`.
- 1인칭 들어 올리기·내려치기·복귀 9개 시점: `target/debug/tsb-review.exe --attack-review --erpin-only --erpin-skill-first-person-only --lan`. 52–60번 캡처에서 지팡이 방향·높이와 손 접점을 검사한다.
