# 방 선택 화면

홈의 **플레이 → 방 선택 → 대전 로비 → 영웅 선택 → 경기** 순서로 이동한다. 방 선택은 `src/presentation/rooms.rs`, HTTPS 통신은 `src/room_directory.rs`, 기존 대전 로비는 `src/presentation/lobby.rs`에 있다.

## 사용

- 시작 화면의 **로그인 / 회원가입**으로 DOTG 인증을 진행한다. 게스트로 시작했다면 홈의 프로필에서 로그인 선택을 다시 열 수 있다. 웹에서 내 게임 화면과 같은 8자리 연결 코드인지 확인하고 **연결 승인**을 누르면 게임이 결과를 자동으로 받는다. 연결 코드는 10분, 승인된 게임 연결은 12시간 동안 유효하다. 방 목록의 웹 계정 연결 버튼은 제거했으며, 연결 자격증명은 실행 중 메모리에만 보관한다.
- **방 만들기**에서 이름을 입력한다. 기본 EOS 빌드는 온라인 방 준비 후 웹에 방을 등록하고 로비로 이동한다. 로비 상단에 방 코드 전체를 표시하고 **코드 복사하기** 버튼으로 복사한다. 웹 목록 방은 8자리 코드를, 직접 EOS 방은 전체 EOS 코드를 표시하며 준비 중에는 복사 버튼을 비활성화한다. `--lan` 또는 EOS 없는 desktop 빌드에서는 접속 주소를 입력하는 UDP 방을 사용한다. `DOTG_HOST_ADDRESS`로 LAN 주소 기본값을 지정할 수 있다.
- **방 참여하기**의 방 코드 입력란에서 코드를 직접 입력하거나 **Ctrl+V**로 붙여넣는다. 기존 `eos:호스트:소켓` 코드와 IP:포트 직접 참여도 유지한다. 목록의 방 행을 눌러 참여할 수도 있다. 목록 코드 참여는 연결된 웹 계정의 서명된 참가권을 사용한다.
- **방 목록**에는 방 이름, 방장, 맵, 실제 인원/12, 상태, 방 코드가 표시된다. 한 페이지 6개이며 다음/이전 버튼으로 이동한다. 자동 갱신은 15초, 수동 갱신은 F5다. 꽉 찬 방은 목록에서 참여할 수 없으며 서버에서도 다시 검사한다.
- 로비의 **방 목록**은 현재 접속을 유지한다. 방에 들어가면 목록 상단의 **방 만들기 / 방 참여하기**가 같은 자리에서 **내 로비로 / 방 나가기**로 바뀐다. **내 로비로**는 현재 로비로 돌아가고, **방 나가기**는 접속과 웹 등록을 종료한 뒤 버튼을 **방 만들기 / 방 참여하기**로 되돌린다. 홈으로 돌아가도 진행 중인 호스트 연결과 버튼 상태는 유지한다.

## 웹 연결

기본 주소는 `https://www.dotgsince2023.co.kr/play`이며 별도 설정 없이 사용한다. 기존 `https://dotgsince2023.co.kr/play` 설정도 동일한 www 주소로 정규화한다. 운영 서버는 www 없는 주소에 HTTP 308을 반환하므로 API는 최종 주소를 직접 사용한다. 기기 토큰이 포함된 요청을 다른 서버로 전달하지 않도록 자동 리다이렉트는 허용하지 않는다. 로컬 개발 등 다른 웹사이트를 사용하려면 `DOTG_PORTAL_URL`로 덮어쓸 수 있으며 외부 서버는 HTTPS가 필요하다.

```powershell
$env:DOTG_PORTAL_URL = 'http://localhost:3000/play' # 로컬 개발 시에만 지정
.\target\debug\tsb.exe
```

DotGwebsite의 `/api/game/rooms`가 게임과 `/play` 웹 목록의 공통 API다. 웹은 로그인 전에도 목록을 보여 주고, 로그인 후 게임 연결 승인·코드 참여·참가 파일 다운로드를 제공한다. 게임은 생성 성공 후 15초마다 맵·인원·상태를 갱신한다. 종료 알림이 실패하거나 비정상 종료되어도 60초간 갱신이 없는 방은 목록과 코드 참여에서 제외한다. 방 자체는 기존 세션과 같이 최대 2시간이다.

웹 배포에는 기존 계정 마이그레이션과 함께 다음 두 파일이 필요하다.

1. `20261113110000_add_game_room_directory.sql`: 기기 연결, 방 목록, 상태 갱신과 참가권 발급.
2. `20261113120000_add_eos_p2p_rooms.sql`: EOS 주소 지원과 기존 UDP 호환.

공개 목록에 접속 주소·기기 토큰·호스트 키를 내보내지 않는다. 방 생성/갱신/종료는 연결된 계정과 생성 기기에 묶인다. 참가권은 기존 호스트 HMAC 검증을 사용하며 차단·만료·종료·가득 찬 방에 새 참가권을 발급하지 않는다. 기존 친구 초대 전용 방은 실시간 등록 없이 자동 공개되지 않는다.

## 검증

- 웹: `test:game-social`에 포함된 `tests/game-rooms.test.mts`에서 실제 PostgreSQL 마이그레이션을 PGlite에 적용해 연결 승인, 권한, 목록 노출 범위, 서명, 인원 제한, 차단, 갱신, 만료, EOS 주소를 검사한다.
- 게임: `room_directory::tests`는 실제 로컬 HTTP 서버로 목록·생성·갱신·종료 요청을 검증한다. presentation 테스트는 UI 좌표와 로컬 UDP 접속을 검사한다.
- 운영 API 읽기 전용 점검: `cargo test --lib room_directory::tests::production_room_directory_returns_a_valid_list -- --ignored --exact`. 인터넷 연결이 필요하며 방 생성·계정 변경 없이 목록만 조회한다.
- `tsb --lobby-review`와 `--lobby-review-small`, `--lobby-review-wide`는 방 목록·페이지 이동·코드 오류·방 생성 창·빈 목록·로딩·오류·연결 코드 및 경기 진입을 GPU로 캡처한다. 이 모드의 방 목록은 검증용 데이터이며 웹에 게시하지 않는다.

운영 웹/DB 배포와 두 PC 사이의 실제 EOS 접속은 로컬 빌드·테스트와 별도다.
