# 시온 모션과 스킬

원본 `assets/references/shion-motion-reference.skel`을 30fps로 샘플링한다.
`scripts/extract_shion_skills.cjs`가 곡선과 IK를 평가하고,
`scripts/bake_shion_skills.py`가 기존 키·모델 형상을 보존하며 FBX에 추가한다.

| 동작 | 원본 프레임 | FBX 구간 |
| --- | --- | --- |
| Skill1_1 | 64 | 531–595 |
| Skill1_1_Loop | 30 | 598–628 |
| Skill1_2 | 40 | 631–671 |
| Ultimate1_1 | 106 | 674–780 |

E는 Skill1_1을 끝낸 뒤 마탄 5발을 충전한다. 조준은 가능하지만 이동·점프·새로운 앉기·Shift·재장전·E/Q는 막힌다. 입력 없이 기다려도 탄환과 자세가 유지된다. 좌클릭을 누르면 Skill1_1_Loop를 한 번 재생하고 원본의 첫 이벤트인 1프레임에 마탄 1발을 발사한다. 누르고 있으면 반복한다. 마지막 발의 사격 모션이 끝나면 Skill1_2를 재생하고 이동을 해제한다. 일반 탄창은 소모하지 않는다.

마탄은 기본 피해 65, 사거리 60m, 기절 0.75초다. 팀 피해 배율은 적용된다. 아군·벽·무적 대상은 관통하지 않으며, 실제 체력/보호막 피해가 발생한 생존 적에게만 기절을 적용한다. 기존 일반 공격의 네 번째 탄환 보너스는 유지한다.

Q는 Ultimate1_1의 80프레임(약 2.667초)에 전방 6m, 반경 4m의 보라색 폭발을 한 번 발생시킨다. 원본 스켈레톤의 이벤트 위치 대신 요청된 80프레임을 명시적으로 사용한다. 폭발 중심은 벽 앞에서 멈추며 피해도 시야 판정을 거친다. 적은 체력·일반 보호막·피해 감소·체력 하한·벨라 부활과 관계없이 즉사한다. 스폰 보호, 이드의 완전 무적, 잠복, 아군에는 적용하지 않는다. 공통 피해 처리로 처치·죽음·통계·리스폰을 기록한다.

기절·수면·죽음은 발동 전 동작을 취소한다. 시간 정지는 시계를 멈춘다. 상태·경과 시간·마탄·폭발 위치는 기존 스냅샷 필드로 전달하므로 패킷 크기가 늘지 않는다. 로컬 이동 예측은 서버와 같은 상태 전이를 사용하고, 폭발 효과는 서버가 확정한 위치와 시각을 사용한다.

검증:

```powershell
cargo test --no-default-features --test shion_skill
cargo test --no-default-features --lib net::shion_tests
cargo run --bin tsb -- --solo --auto-start --shion-skill-review --lan
```

GPU 검토는 원본 4개 동작과 80프레임 전후 폭발, 1인칭 라이플을 14장 캡처한다.

## 1인칭 라이플과 줌 레이저 (2026-11-21)

1인칭 라이플 배율을 0.72에서 1.30으로 약 81% 확대하고 화면 안쪽으로 배치했다. 양손은 확대된 라이플의 접점을 따라간다. 월드 무기의 배율은 기존과 같다.

우클릭 조준 중 발사하면 일반 탄환 모형 대신 흰 중심과 보라색 광채가 있는 레이저를 0.18초 동안 표시한다. 발사 순간의 총구와 확정된 명중 지점을 연결하며 반동으로 광선이 끌려가지 않는다. 근접 명중에서는 총구 뒤로 광선이 역주행하지 않도록 시작점을 보정한다. 기존 로컬 줌을 기준으로 시각 효과만 분기하므로 피해·사거리·탄약과 서버 판정은 유지된다.

`--weapon-review --shion-only --solo --auto-start --hud-review-small --lan`은 대기·줌·레이저 발사·조준 해제·선택 화면·일반 탄환·재장전·외부 시점 2장을 검증한다. 레이저/탄환의 배타적 표시, 명중 지점, 양손 파지까지 포함한 9개 GPU 장면을 통과했다. 캡처와 로그는 `artifacts/shion-view-laser/`에 보관한다. 실행은 `Play.cmd`를 사용한다.

`cargo test --offline --locked --test shion_skill`의 전투 회귀 테스트 8개도 통과했다.
