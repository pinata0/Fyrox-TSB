# 코미 스킬

`Play.cmd`는 코미 스킬이 포함된 최신 소스의 게임을 빌드하고 실행한다.
`Play.cmd --solo --komi-skill-review --lan`은 화면 검증 11장을 자동 저장하고 종료한다.

평소 1인칭에서는 오른손으로만 베개를 잡는다. 휴식·사료 먹기·거대화 중에는 기존 양손 동작을 사용하고, 종료하면 한 손 베개 자세로 복귀한다.

1인칭 베개는 기존 대비 약 1.8배 크기다. 기본공격은 오른손으로 베개 가장자리를 쥔 채 어깨 옆으로 들어 올리고, 화면 중앙을 지나 왼쪽으로 크게 휘두른 뒤 원래 자세로 돌아온다. 기존 공격 시계(공격 속도 효과·데스캠 포함)를 따르며, 전용 1인칭 궤적은 `src/attack.rs`에 있다.

`Play.cmd --solo --auto-start --attack-review --komi-only --hud-review-small --lan`으로 준비·휘두르기·복귀 11개 시점의 화면과 오른손 파지 접촉을 검증한다.

2026-11-20 검증: 공격 관련 단위 테스트 7개 통과, `tsb`·`tsb-review` 빌드 성공. 1인칭 GPU 캡처 11장과 파지 오차 1mm 미만·왼손 숨김·복귀 검사 통과(`artifacts/komi-pillow/attack-review.log`).

| 입력 | 원본 모션 | 현재 동작 |
| --- | --- | --- |
| E / 저학년 | Skill1_1 | 4초 동안 이불에서 휴식. 피해·해로운 효과·밀쳐내기 차단, 자신에게 총 48 회복. 재사용 12초 |
| Q / 고학년 | Ultimate1_1 | 원본 4.4초 사료 먹기. 마지막 1.1초에 커지고, 준비가 끝나면 8초간 1.8배 크기 유지 |
| 거대화 중 Shift | 수인 도약 | 재사용 1초. 실제 착지 시 주변 5m의 적에게 기본 70 피해 |

회복은 0.25초마다 3씩 16회 적용한다. 과회복은 버리며 기존 받는 치유 보정과 치유 통계를 사용한다.
저학년은 지상에서 시작한다. 채팅 입력 중에는 취소하지 않는다. Enter로 채팅을 열고 닫거나
IME로 글을 쓰는 동안에도 유지된다. 그 외 키, 마우스 버튼, 휠 입력은 즉시 휴식을 해제한다.
마우스로 시선을 돌리는 동작과 최초 E를 계속 누르는 동작은 해제하지 않는다.
E를 놓았다 다시 누르면 해제한다. 취소한 뒤에는 남은 회복과 무적이 이어지지 않는다.

고학년 준비 중에는 이동·공격·도약을 잠근다. 거대화 중에는 이동과 도약이 가능하고,
기본공격 및 저학년·고학년의 중복 사용은 막는다. 1인칭과 외부 시점의 베개는 숨기고
양손을 표시한다. 종료하면 크기·시점·무기·공격 및 정상 도약 쿨타임 규칙으로 복귀한다.
기존에 진행 중인 도약 쿨타임은 거대화 시작 시 최대 1초로 줄인다.

착지 피해는 도약 한 번당 한 번만 발생한다. 아군과 벽 뒤의 적은 제외하며, 기존 팀 조합과
공격·방어 보정을 적용하므로 실제 피해는 기본 70과 다를 수 있다. 일반 점프, 도약 취소,
시간 초과, 거대화가 끝난 뒤의 착지는 강화 피해를 주지 않는다. 피해 판정은 서버에서만 한다.
사망·캐릭터 변경·기절·동결·변이 시 스킬 상태를 정리한다. 휴식과 거대화의 효과 시간은
시간 감속으로 늘어나지 않는다. 성장한 크기는 렌더링·시점·피격 범위에 반영하며,
지형 이동 충돌에는 기존 공통 몸체 크기를 사용한다.

## 아트

- `assets/characters/skill/komi.json`: 보관된 Spine 원본의 곡선과 IK를 30Hz로 평가한 몸·손 샘플, 이벤트와 소품 표시 타이밍.
- `assets/characters/komi.blend`, `komi.fbx`: 기존 메시와 0–528프레임을 보존하고 `KomiRest` 531–716, `KomiFeast` 719–851 추가.
- `assets/effects/komi-props.blend`: 편집 가능한 누빔 이불·베개와 열린 사료통. 사료통 뚜껑은 독립 파트.
- `assets/effects/komi-blanket.glb`, `komi-food-can.glb`: 각 소품의 독립 모델.
- `assets/effects/komi-props.json`: 게임에서 사용하는 동일한 삼각형 메시.

휴식은 원본의 진입·기상 동작 속도를 유지하고 잠든 중간 구간을 줄여 4초에 맞춘다.
키 취소는 모션 종료를 기다리지 않고 즉시 일어난다. 스킬 상태·모션 시계·착지 효과를
캐릭터별 기존 네트워크 필드에 기록하므로 스냅샷 크기를 늘리지 않는다.
채팅 외 취소 입력도 기존 입력 비트에 포함한다. 클라이언트 이동 예측은 같은 상태 전환을 사용한다.

## 재생성 및 확인

1. `node scripts/extract_komi_skills.cjs`
2. Blender 백그라운드에서 `scripts/model_komi_props.py`, `scripts/bake_komi_skills.py` 실행.
3. `cargo test --offline --no-default-features --test komi_skill --test combat`
4. `cargo test --offline --no-default-features --lib komi`
5. `cargo build --offline --bin tsb-review`
6. `Play.cmd --solo --komi-skill-review --lan`

`artifacts/komi-skills/bake-verification.json`에 기존 키·메시 보존 검사 결과를 저장한다.
`artifacts/preview-komi-skills-*`에는 이불 3장, 사료 먹기 3장, 거대화 비교,
1인칭 휴식·먹기·맨손·베개 복귀 화면을 저장한다.
