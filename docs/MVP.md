# MVP 사양

게임명: **Trickcal : Shooting Balddagu**

비공식 팬게임의 동작 검증용 프로토타입. **6 대 6** 두 팀(BLOOM / COCOA)이 두 거점을 공격/수비한다. 빈 자리는 봇으로 채우며 참가자는 봇을 대체한다.

**2026-11-12 확장 구현:** 승인된 15명, 캐릭터 선택, 팀 전체 성격 시너지, 7종족 패시브, 포지션 상한과 원작 기반 LMB/E/Q 키트, 개별 Blender 모델·11종 동작·춤 관찰을 반영했다. 전체 목록과 수치는 [로스터 설계](ROSTER_PLAN.md), 아트와 동작은 [캐릭터 아트](CHARACTER_ART.md), 조작은 [README](../README.md)를 참조한다.

## 캐릭터와 전투

- 한 팀 6명, 같은 캐릭터 중복 금지. 다른 팀과 미러 선택 가능. 각 포지션 최대 3명.
- 기본 팀: 비비·코미 / 나이아·우이 / 버터·시온. 포지션 2/2/2, 순수·활발·우울 각 2명, 공격력 +60%.
- 선택 가능 시점: 로비, 준비 시간, 공수 교대, 종료, 사망 중, 현재 아군 스폰 구역 안. 봇의 선택은 교환 가능. 서버가 원자적으로 판정하고 거부 이유를 응답한다.
- 시너지는 현재 로스터에서 `20% × Σ floor(성격별 인원 / 2)`. 사망·부활은 집계에 영향 없음. 기본공격·E·Q 피해에 적용하며 치유량에는 적용하지 않는다.
- 체력 120, 캐릭터별 무기·탄창·사거리·공격 간격. 팀 배율과 상태 효과 적용 후 정수 반올림. 보호막 흡수 후 남은 체력 피해는 올림.
- LMB 기본공격 / E 저학년 / Q 고학년. 15명의 원작 조사·FPS 각색·수치·제약은 [캐릭터 키트](CHARACTER_KITS.md) 참고.
- 생존 전투 시간 초당 1.25%, 실제 적 체력/보호막 피해 1당 0.12% 궁극기 충전. Q를 새로 누르면 100% 소모. 궁극기 자체 피해는 충전에서 제외. 사망 시 유지, 캐릭터 변경 시 최대 15% 보존, 새 공수 라운드에 초기화.
- 근접은 탄약 없는 부채꼴, 원거리는 즉시 적중 또는 이동 투사체. 중력·왕복·튕김·폭발·유도 등 유형 구분. 모든 공격/회복은 거리와 엄폐를 검사하며 밀쳐내기·돌진은 작은 구간마다 벽 충돌 검사.
- 스킬 보호막은 정령 패시브 보호막과 별개이며 최대 120. 독·동상은 출처별 지속 피해, 원작 SP는 E 쿨타임 증감으로 대응한다. 마녀는 E 쿨타임에만 -5%.
- 정령 보호막은 비피격 4초 뒤 9.6까지 복구하며 중첩되지 않는다. 유령은 Shift 공용 스킬로 3초간 벽을 통과하며, 만료 시 벽 밖으로 배출되고 12초 쿨타임이 시작된다. 접촉면 파문과 바닥·천장·외곽 충돌은 유지한다. Shift 질주와 수인 질주 보너스는 제거했다. 전체 종족 특성은 로스터 문서에 기재한다.
- 변경 시 체력/E 쿨타임/리스폰 대기는 유지하며 궁극기를 최대 15%로 제한하고 개인 상태·종족 보호막·벽 접촉 상태·자기 투사체는 제거한다. 탄약은 새 탄창 이하로 유지하되 비전투 변경에서는 채운다. 선택은 경기 재시작과 공수 교대에도 유지된다.
- G를 새로 누르면 춤 시작/종료. 이동·전투 입력·피격·사망·교체·라운드 전환·봇 인계로 취소하며, 서버가 상태를 모든 참가자에게 전송한다. 춤 동안 카메라만 회전/줌하므로 조준 방향은 유지되고 취소 시 1인칭으로 복귀한다.
- 15명 각각 편집 가능한 Blender 모델·20본 리그·11종 동작을 FBX로 불러온다. 캐릭터별 원작 이미지/모션 조사와 삼면도를 보관하며, 얼굴·의상은 단순화한 MVP 아트다.

선택 화면·스폰 구역과 보존 규칙: [영웅 선택 사양](HERO_SELECTION.md).

## 경쟁전 규칙

- 기본 공격 4분. A 점령 시 3분 추가, B는 A 점령 전 잠김.
- 공격자만 점령 가능. 수비자가 거점에 있으면 진행 정지.
- 점령 가속은 공격자 3명에서 상한. 6명이 모여도 추가 가속하지 않는다.
- 1/3과 2/3 점령 틱 보존. 공격자가 5초간 없으면 마지막 틱까지 감소.
- 제한 시간에 공격자가 거점에 있으면 오버타임. 이탈 후 3초간 재접촉 없으면 종료.
- 공수 교대 후 두 팀의 최고 점령률을 비교. 최소 1/3 이상 진행해야 점령률로 승리 가능.
- 양쪽 B 완전 점령 시 남은 시간으로 추가 공수 라운드. 추가 라운드는 A 점령 시간 보너스 없음.
- 양 팀 시간 최소값이 2분을 넘으면 동일량을 차감해 짧은 쪽을 2분으로 맞춤. 1분 미만이면 동일량을 추가해 1분으로 맞춤.
- 한 팀은 0초, 상대는 1분 이상일 때 상대만 공격하며 A의 1/3을 확보하면 승리, 실패하면 무승부.
- 같은 점령 결과로 양쪽 시간이 0이면 무승부. 추가 라운드 순서는 시간이 적은 팀부터.
- 원작의 특정 시즌 전체 복제는 아님. 준비 시간, 인원 수, 리스폰 시간, 점령 속도, 오버타임 감소는 MVP에 맞춤.

## 구현 구조

- `src/game.rs`: 그래픽 및 네트워크와 독립적인 고정 틱 시뮬레이션.
- `src/level.rs`: A/B 양쪽 2층 건물·열린 창문·계단·발코니·연결 다리의 공유 블록 형상.
- `src/movement.rs`: 높이를 포함한 몸체 충돌, 0.32m 계단 오르기, 바닥·천장·착지 판정.
- `src/navigation.rs`: 0.5m 격자에 같은 위치의 여러 층을 담은 경로 그래프. 충돌 형상이 바뀌면 캐시를 재생성한다.
- `src/roster.rs`: 승인된 15명의 고정 ID, 성격/종족/포지션/지원 역할, 패시브 설명.
- src/kits.rs: 15개 키트의 이름, 무기, 초기 튜닝 데이터.
- src/combat.rs: 공격, 스킬, 궁극기, 상태, 투사체의 서버 판정.
- `src/net.rs`: UDP 세션, 입력, 전체 스냅샷. 클라이언트는 체력/위치를 지정할 수 없음.
- `src/presentation.rs`: Fyrox 장면, 입력, HUD, 시각 효과. src/presentation/weapons.rs에서 15종 절차 무기 생성.
- `src/presentation/characters.rs`: 15개 FBX 로딩, 캐릭터 교체, 손 무기 연결, 상태별 애니메이션 재생.
- `src/emote.rs`: 춤 관찰용 궤도·줌·벽/바닥 카메라 충돌 및 춤 상태 테스트.
- `scripts/build_characters.py`: Blender 모델·리그·동작 생성. `verify_character_art.py`는 모든 리그·클립·가중치·루프 검증.
- `src/bin/server.rs`: 그래픽 없는 전용 서버.
- `tests/`: 규칙과 실제 루프백 UDP 검증.

UDP TSB4: 12인 전체 스냅샷은 이벤트 최대 길이에서도 1200바이트 미만. 투사체는 최대 96개를 별도 1200바이트 미만 패킷으로 전송한다. 궁극기/상태/보호막/마탄/춤을 동기화하고 Q·G 사용은 서버가 판정한다. 춤은 기존 actor/입력 바이트의 비트를 사용해 패킷 크기를 유지하며 서버 tick으로 반복 위상을 맞춘다. 선택 요청은 세션 토큰과 순번으로 확인하고 응답 유실 시 200ms 간격 재전송한다. 같은 순번은 재적용하지 않는다. 실제 12개 클라이언트로 선택 경합과 상태 전파를 검증한다.


## 2026-11-12 / 입체 맵

2층 높이는 3.6m이며 모든 캐릭터가 외부 계단으로 올라갈 수 있다. 1층 실내, 2층 방과 발코니, 연결 다리 위·아래를 사용할 수 있다. 창문은 벽 조각 사이의 실제 개구부이며 창턱은 0.65m라 점프로 넘을 수 있다. 낮은 발코니 난간과 중앙 개방부를 통해 지상으로 내려갈 수 있다. 같은 블록 목록을 서버 충돌·사격 판정·Fyrox 렌더링에 사용한다.

점프 시작과 감정 표현은 절대 높이 대신 접지 여부를 검사하고, 2층에 서 있을 때 대기/걷기 애니메이션을 사용한다. 거점 위 2층에서는 점령되지 않는다. 맵 버전이 다른 클라이언트의 접속을 막기 위해 프로토콜을 TSB8로 변경했으며 호스트·참가자 모두 새 빌드를 사용해야 한다.

현재 결과물은 블록아웃이다. 세부 환경 아트와 사람끼리의 전투 밸런스 검증은 아직 수행하지 않았다. 봇은 층별 경로를 이용할 수 있으나 고지 선점 전술을 따로 추가한 것은 아니다. `--map-review --auto-start`로 6개 시점의 실제 GPU 화면을 재현한다.
