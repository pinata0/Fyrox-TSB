# 힐데 구급상자와 의료용 유탄발사기

`Play.cmd`로 현재 개발 빌드를 실행한다. 기존 게임 실행 파일이 사용 중이어도
확인할 수 있도록 `target/debug/tsb-review.exe`를 별도로 빌드한다.

| 입력 | 참고 모션 | 동작 |
| --- | --- | --- |
| E / 저학년 | Skill1_1, 원본 3.3초 | 약 1.37초에 구급상자를 연 뒤 주변 9m의 자신과 모든 아군을 2초 동안 회복 |
| Q / 고학년 | Ultimate1_1, 원본 약 6.17초 | 2.1초 준비 후 유탄발사기를 6초간 사용. 좌클릭 유지로 연사 |

기본 회복량은 총 40이며 0.5초마다 10씩 네 번 적용한다. 매 회복 시 범위와 시야를 확인한다.
사망·비활성·잠복 대상은 제외하고, 과회복을 제외한 실제 회복만 힐데의 치유 통계에 기록한다.
요정의 받는 회복 증가 등 기존 치유 보정도 유지한다. 재사용 대기시간은 기존 10초다.
범위 원과 공통 파란 스킬 원은 표시하지 않는다. 회복이 시작되면 9m 구역 안에서 초록 십자가
파티클이 위로 떠오르고 사라지는 효과를 2초간 반복한다. 시전 종료·취소 시 효과도 사라진다.

유탄은 초당 5발, 6초 동안 최대 30발이다. 좌클릭을 놓으면 사격을 멈추며 조준·이동은 가능하다.
기본 주사총 탄약과 재장전을 사용하지 않는다. 준비·사격·종료 중 E와 Q의 중복 시전을 막고,
기절·수면·동결·사망·캐릭터 교체 시 취소한다. 시간 감속은 시전 시계에 적용한다.
Shift로 포탈을 설치하는 동안 유탄은 발사하지 않는다. 사용 시간이 끝나면 원본의 정리 동작 후 주사총으로 복귀한다.

유탄 속도는 22m/s, 중력은 5m/s²다. 캐릭터·지형·바닥 충돌 또는 수명 종료 시 한 번 폭발한다.
유탄은 1인칭과 외부 시점 모두 애니메이션이 적용된 유탄발사기의 총구에서 나타난다.
발사 순간의 위치를 저장하고 0.1초 동안 실제 탄도로 이어져 이후 총의 움직임에 끌려가지 않는다.
착탄 위치에 초록색 섬광·팽창하는 폭발 구름·방사형 입자가 0.65초간 나타난 뒤 사라진다.
벽·바닥·아군·적군 모두 같은 효과를 사용하며, 서버의 착탄 위치와 시각을 멀티플레이 및 사망 재생에도 전달한다.
2.2m 폭발 범위의 아군은 기본 16 회복, 적군은 기본 14 피해를 받는다.
피해량은 기존 공격/방어 보정을 거치며 아군에게 피해를 주지 않는다. 폭발의 회복·피해는 벽을 통과하지 않는다.

## 아트와 원본 모션

- `assets/effects/hilde-medical-props-concept.png`: 내장 image_gen으로 생성한 시안.
- `assets/effects/hilde-medical-props-prompt.txt`: 생성에 사용한 전체 프롬프트.
- `assets/effects/hilde-medical-props.blend`: 시안을 참고해 모델링한 구급상자와 회전식 의료용 유탄발사기.
- `assets/effects/hilde-medical-props.json`: 실제 게임에서 공유하는 삼각형 메시. 뚜껑과 탄창을 독립적으로 회전한다.
- `assets/characters/skill/hilde.json`: 보관된 Spine 원본의 곡선·IK를 30Hz로 평가한 몸과 손 샘플.
- `hilde.blend` / `hilde.fbx`: 기존 메시·얼굴과 0–528프레임 키를 보존하고 E 531–630, Q 633–818 추가.

Q는 원본 2.1–4.43초의 연사 구간을 반복한다. 손을 놓으면 준비 자세를 유지하며, 6초가 지나면
원본 4.43–6.17초의 종료 구간으로 이어진다. 1인칭·외부 시점·관전자·사망 재생에서 같은 시계를 사용한다.
1인칭 양손과 외부 시점의 손 접촉점을 실제 소품 손잡이에 맞춘다. 스킬 중 1인칭은 원본 힐데 손과
카메라에 맞춘 별도 소매 메시를 사용한다. HUD에 유탄발사기와 남은 시간이 표시된다.

## 재생성과 검증

1. `node scripts/extract_hilde_skills.cjs`
2. Blender 백그라운드에서 `scripts/model_hilde_props.py` 실행.
3. Blender 백그라운드에서 `scripts/bake_hilde_skills.py` 실행.
4. `cargo test --offline --no-default-features --test hilde_skill`
5. `cargo test --offline --no-default-features --lib hilde_tests`
6. `cargo build --offline --bin tsb-review`
7. `target/debug/tsb-review.exe --solo --hilde-skill-review --lan`
8. `target/debug/tsb-review.exe --solo --impact-review --hilde-grenade-review --auto-start --lan`

착탄 화면 검증은 실제 유탄으로 벽·바닥·캐릭터에 충돌시킨 뒤 폭발·감쇠·소멸을 캡처한다.
결과는 `artifacts/preview-impact-medical-*-game.png`에 저장된다.
착탄 효과 보강 검증: 힐데 전투 8개, 힐데 네트워크 3개, 착탄 관련 공통 테스트 9개,
렌더링 수명·중복 방지 테스트 2개 통과.

원본 키·메시 보존 검증은 `artifacts/hilde-skills/bake-verification.json`에 저장한다.
화면 검증은 구급상자·유탄발사기·복귀 12장과 양손 접촉점 검사를 포함한다.
회복 구역 전체의 십자가 파티클, 범위 원 제거, 실제 발사된 유탄의 양 시점 총구 정렬도 검사한다.
게임플레이 테스트는 아군 6명 회복, 지연·지속시간, 사망·거리·벽 차단,
유탄 회복/피해·중복 방지·조준 변경·입력 취소·30발 제한을 검사한다.
네트워크 테스트는 상태와 의료용 유탄의 직렬화 및 패킷 크기 유지를 검사한다.
프로토콜은 `TSBH`이며 멀티플레이 참가자는 같은 빌드를 사용해야 한다.

검증 결과: 힐데 전투 7개, 공통 전투 35개, 힐데 네트워크 2개, 요정 치유 보정 1개 통과.
전체 로스터 테스트에서는 힐데와 무관한 아야의 즉시 투사체 생성을 기대하는
`dragon_resists_shockwave_and_witch_cooldown_applies_without_repeat_cast`가 실패한다.
현재 아야의 원본 모션 발사 지연과 기존 테스트 기대값의 차이다.
