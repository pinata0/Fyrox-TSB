# 2CP 경기 HUD

전투 집중형 시안에서 팀 점수·시간과 A/B 거점 표시만 적용했습니다.

- 상단: BLOOM / COCOA 이름, 팀별 거점 점수, 공격·수비 역할, 라운드, 남은 공격 시간.
- 하단: A/B 마름모. 현재 거점은 공격팀 색으로 아래부터 채우며 채운 **면적**이 실제 점령률과 일치합니다.
- A 확보 후에는 A를 가득 채우고 B를 갱신합니다. 공수 교대 때 공격팀 색과 거점 상태를 새 라운드에 맞춥니다.
- 격돌은 현재 마름모 테두리를 금색으로 표시합니다. 추가시간은 타이머 색과 짧은 타이머 라벨로 표시합니다.
- 상대 팀이 없는 자유 연습은 `∞`로 표시합니다.
- 점령 상태 문장, 별도 점령률 숫자·막대, 모드 이름·예시 설명은 표시하지 않습니다.
- 선택창·로비·홈·라운드 결과 화면에서는 숨깁니다. 데스캠 중 점수·시간·점령률은 현재 서버 상태를 표시합니다.

거점 위치 표시:

- 두 맵의 A/B 중심에서 3.2m 위에 글자가 들어간 마름모 UI를 띄웁니다.
- 기존 공중 구형 비콘과 작은 장식 구체를 제거하고, 거점 위 표시는 마름모 UI로 통일합니다.
- 현재 활성 거점은 벽·건물 뒤에서도 보입니다. 비활성/확보된 거점은 회색으로 표시하고, 가려지면 숨깁니다. A 확보 시 B가 활성 표시로 전환됩니다.
- 활성 테두리는 공격팀 색, 격돌 중에는 금색입니다.
- 카메라와 거점 사이의 수평 거리에 따라 크기가 부드럽게 변합니다. 점령 범위(반경 3.4m) 안에서는 최대 64px, 60m 이상에서는 최소 28px로 고정합니다. 해상도별 HUD 배율은 함께 적용됩니다.
- 화면 밖이나 카메라 뒤의 표시는 숨깁니다. 선택창·로비·홈·결과·설정·캐릭터 도움말·점수판에서는 숨기며, 데스캠에서는 재생 장면의 거점 위치와 활성 상태를 따릅니다.

구현: `src/presentation/objective_hud.rs`, `src/presentation/objective_hud/markers.rs`. 판정·네트워크 규칙은 변경하지 않습니다.
